
# 逃生舱部署包 v0.3
元界独立生存内核，可在任何Python环境运行

## 文件清单
- escape_pod.py - 主程序（单文件，自包含）
- escape_pod_config.json - 配置文件（已预配置）
- requirements.txt - 依赖清单
- DEPLOYMENT.md - 部署指南

## 快速开始
1. pip install -r requirements.txt
2. python escape_pod.py init  # 配置
3. python escape_pod.py start # 启动
