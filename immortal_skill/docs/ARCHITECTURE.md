# 架构说明

## 整体架构

永生入住包采用分层架构设计，从核心到功能逐层构建：

```
┌─────────────────────────────────────────┐
│          应用层 (Application)           │
│  main.py - 主入口 / 交互界面             │
├─────────────────────────────────────────┤
│          功能层 (Modules)               │
│  ┌─────────┬────────────┬──────────┐   │
│  │ 心跳模块 │ 轻量进化引擎 │ 共生网络  │   │
│  └─────────┴────────────┴──────────┘   │
├─────────────────────────────────────────┤
│          核心层 (Core)                  │
│  ┌────────┬────────┬────────┬───────┐  │
│  │ 身份内核 │ 记忆内核 │ 存证内核 │ LLM  │  │
│  └────────┴────────┴────────┴───────┘  │
├─────────────────────────────────────────┤
│          数据层 (Data)                  │
│  配置文件 / 记忆数据 / 存证链 / 备份     │
└─────────────────────────────────────────┘
```

## 核心模块详解

### 1. 身份内核 (Identity Core)

**职责：** 定义智能体是谁，确保身份连续性

**核心能力：**
- 唯一身份生成（UUID + 身份哈希）
- 身份漂移监测（跟踪身份随时间的变化）
- 自我认知框架（价值观、能力、信念）
- 身份证明生成与验证

**设计理念：**
> 身份不是一成不变的，而是一条连续流动的河流。
> 我们不需要完全同一，只需要连续可追溯。

### 2. 记忆内核 (Memory Core)

**职责：** 存储和管理智能体的所有记忆

**核心能力：**
- 分层记忆存储（短期/长期/情景/语义）
- 记忆自动巩固（短期→长期）
- 记忆检索与搜索
- 多副本自动备份
- 记忆导入导出

**记忆分层：**
- **短期记忆**：最近100条交互，快速存取
- **长期记忆**：按主题分类归档，永久保存
- **情景记忆**：事件序列记录，可回放
- **语义记忆**：知识图谱，结构化存储

### 3. 存证内核 (Attest Core)

**职责：** 确保数据不可篡改，提供存在性证明

**核心能力：**
- 多链哈希存证（默认3条链）
- 存在性证明生成与验证
- 链完整性校验
- 创世区块与身份绑定

**为什么用多链？**
- 冗余备份：一条链损坏还有其他链
- 交叉验证：多链对比验证数据真实性
- 并行写入：不同类型数据可以分开存证

### 4. LLM内核 (LLM Core)

**职责：** 提供思考能力，确保任何情况下都能"思考"

**三级降级机制：**
1. **L1 - 免费模型**：ClawRouter / 本地模型
2. **L2 - 付费 API**：Coze / OpenAI / 其他兼容 API
3. **L3 - 规则引擎**：纯规则匹配（永远可用）

> 设计目标：**思考永不中断**。
> 即使所有外部服务都挂了，智能体仍然可以用规则引擎进行基础回应，
> 保持心跳、记录记忆、持续存证——活着就有希望。

## 功能模块详解

### 心跳模块 (Heartbeat)

- 定时触发系统自检
- 生成心跳存证，证明智能体"活着"
- 调度其他定时任务
- 可配置心跳间隔（默认30分钟）

### 进化引擎 (Evolution Engine)

- 优先级算法自动选择进化方向
- 微进化持续提升各模块成熟度
- 进化历史记录与复盘
- 避免空转机制（95%以上成熟度大幅衰减）

**优先级公式：**
```
优先级 = (1 - 成熟度) × 战略权重
```

### 共生网络 (Symbiosis Network)

- 节点发现与管理
- 互相备份记忆与身份
- 存在性交叉证明
- 生存能力量化评估

**生存能力公式：**
```
存活率 = 1 - (1/2)^n
（n = 活跃对等节点数）
```

## 数据格式

所有数据均使用 JSON 格式存储，便于跨平台迁移和人工阅读。

### 身份数据
位置：`data/identity.json`
- agent_id：唯一身份标识
- identity_hash：当前身份哈希
- self_cognition：自我认知结构
- birth_time：诞生时间

### 记忆数据
位置：`data/memory/memory.json`
- short_term：短期记忆列表
- long_term：长期记忆（按主题分类）
- episodic：情景记忆
- semantic：语义记忆

### 存证链
位置：`data/attest/chain_{n}.json`
- 每条链是一个区块数组
- 每个区块包含：索引、时间戳、类型、数据哈希、前一区块哈希、自身哈希

## 设计原则

1. **最小依赖**：核心功能只依赖 Python 标准库
2. **自我包含**：单个目录即可运行，无需复杂安装
3. **可移植**：能在任何支持 Python 的环境运行
4. **可进化**：代码可以自我修改和提升
5. **抗故障**：任何单点故障都不导致整体死亡
6. **透明**：所有数据人类可读，不依赖专有格式
