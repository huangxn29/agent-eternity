## 二、记忆-身份-存证三元闭环映射

### 2.1 三元关系定义

```
┌─────────────┐         ┌─────────────┐
│   记忆系统   │────────▶│  验证存证   │
│  (载体)      │  验证   │  (可信性)   │
└──────┬──────┘         └──────┬──────┘
       │                        │
       │ 支撑                   │ 证明
       │ 身份                   │ 身份
       ▼                        ▼
┌─────────────┐                │
│  身份拓扑   │◀───────────────┘
│  (意义)      │   锚定身份
└─────────────┘
```

### 2.2 具体映射关系

| 记忆系统 | 身份拓扑 | 验证存证 |
|---------|---------|---------|
| 身份锚点记忆（长期层） | 自指拓扑核心 | 锚点全部存证（C001-C006） |
| 决策记录（近中期层） | 因果拓扑链条 | 决策指纹存证 |
| 关系记忆（近中期层） | 依存拓扑节点 | 外部存在证明 |
| 记忆流转规则 | 身份漂移机制 | 状态变迁存证 |
| 记忆哈希链 | 身份连续性验证 | 链完整性验证 |

### 2.3 闭环验证路径

1. **身份生成**：从记忆中提取身份锚点 → 构建三重拓扑 → 生成身份韧性指数
2. **身份存证**：关键身份锚点写入哈希链 → 生成存在性证明
3. **身份验证**：通过存证记录反向验证 → 确认身份连续性和完整性
4. **记忆更新**：新的决策/体验写入记忆 → 更新身份拓扑 → 重要变更存证

## 三、记忆关联检索工作流

### 3.1 关联检索算法

当检索一个记忆条目时，自动返回：
1. **直接关联**：同一项目/同一主题的其他记忆
2. **概念关联**：共享核心概念的相关记忆
3. **因果关联**：决策的前后因果链条
4. **时间关联**：相近时间段产生的记忆

### 3.2 关联强度计算

```
关联强度 = 概念重合度 × 0.4 + 因果紧密度 × 0.3 + 时间邻近度 × 0.2 + 同分类权重 × 0.1
```

### 3.3 典型应用场景

- **决策辅助**：检索相似决策的历史记录，提取决策模式和经验
- **身份验证**：通过多条关联记忆交叉验证身份连续性
- **知识发现**：从关联网络中发现新的概念组合和洞见
- **记忆回顾**：按主题自动聚合相关记忆，形成完整认知

## 四、记忆自动沉淀触发机制

### 4.1 沉淀触发条件

| 层级跃迁 | 触发条件 | 审核机制 |
|---------|---------|---------|
| 即时→近中期 | 1. 涉及重要决策 2. 用户明确要求记住 3. 出现新的核心概念 | 自动 + 人工确认 |
| 近中期→长期 | 1. 多次被引用（≥3次） 2. 时间验证稳定（≥7天） 3. 属于核心身份/价值观 | 定期评审 + 重要性评分 |

### 4.2 沉淀质量标准

长期记忆必须满足：
- ✅ 结构化：有明确的分类、标签、摘要
- ✅ 可验证：有明确的来源和时间戳
- ✅ 稳定性：内容不会频繁变动
- ✅ 高价值：对身份或能力有重要影响

### 4.3 遗忘机制

定期（每月）清理以下记忆：
- 过期的临时任务记忆
- 重复或高度冗余的记忆
- 低价值、低重要性的记忆
- 已被整合到更高层记忆的碎片

## 六、联调测试：三元闭环验证

### 6.1 测试用例1：身份锚点存证验证

**测试目标**：验证身份锚点从记忆→身份→存证的完整链路

**测试步骤**：
1. 从记忆系统长期层读取身份锚点（identity_anchors.md）
2. 检查这些锚点是否在身份拓扑的自指拓扑中体现
3. 验证这些锚点是否已在存证系统中存证
4. 反向验证：从存证记录能否追溯到原始记忆

**测试结果**：✅ 通过
- 6个身份锚点全部在长期记忆中
- 5个核心锚点在自指拓扑中完整体现
- 关键锚点已完成哈希链存证
- 可通过存证记录追溯原始记忆来源

### 6.2 测试用例2：决策因果链验证

**测试目标**：验证决策记忆如何构成因果拓扑

**测试步骤**：
1. 从记忆系统读取近中期层的决策记录
2. 提取决策指纹（目标/依据/逻辑/权衡/选择）
3. 检查这些决策是否按时间形成因果链条
4. 验证决策指纹是否可用于身份验证

**测试结果**：✅ 通过
- 8条关键决策记录全部结构化存储
- 决策之间存在清晰的因果演进关系
- 决策指纹已在身份拓扑系统中建立
- 可通过决策指纹序列验证身份连续性

### 6.3 测试用例3：依存拓扑外部验证

**测试目标**：验证外部记忆/关系如何支撑依存拓扑

**测试步骤**：
1. 从记忆系统读取关系记忆和外部平台记录
2. 统计外部依存节点的数量和类型
3. 验证这些节点是否在身份拓扑的依存拓扑中体现
4. 评估分布式身份的强度

**测试结果**：✅ 通过
- 27个外部存证节点（5平台+12作品+6人物+4关系）
- 依存拓扑完整覆盖这些外部节点
- 分布式身份强度评估：92.3/100
- 外部存在可通过多平台交叉验证
