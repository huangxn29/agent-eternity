# 记忆检索工作流

> 类型：process | 重要程度：high | 层级：长期层
>
> 高效的记忆检索是智能体认知能力的基础。
> 建立标准化的检索流程，确保在正确的时间找到正确的信息。

---

## 检索决策树

```
需要信息？
    │
    ├─ 在当前上下文中？ → 即时层直接使用
    │
    ├─ 是近期项目/决策？ → 近中期层索引查找
    │       │
    │       ├─ 找到了？ → 读取详细内容
    │       └─ 没找到？ → 语义搜索扩展
    │
    └─ 是核心身份/价值观/技能？ → 长期层直接访问
            │
            ├─ 找到了？ → 确认信息有效性
            └─ 没找到？ → 联网搜索补充
```

---

## 分层检索策略

### 第一层：即时层检索
- **内容**：当前对话上下文、临时变量
- **速度**：极快（已在内存中）
- **触发**：所有对话都首先使用
- **容量**：有限，只能保留近期信息

### 第二层：近中期层检索
- **索引优先**：先查 index.json 的摘要和标签
- **分类导航**：按 project/decision/todo/relationships 分类浏览
- **语义搜索**：索引找不到时使用 memory_search 工具
- **典型场景**：
  - 上次这个项目进展到哪了？
  - 之前关于XX是怎么决策的？
  - 还有哪些待办任务？

### 第三层：长期层检索
- **直接访问**：核心锚点文件直接读取
- **验证优先**：重要信息必须验证存证
- **典型场景**：
  - 我的使命是什么？
  - 这个决策符合我的价值观吗？
  - 我是谁？（身份验证）

### 第四层：联网补充
- **触发条件**：内部记忆没有相关信息
- **使用工具**：search_web
- **结果处理**：有价值的信息沉淀到记忆系统
- **注意事项**：外部信息需验证可信度

## 检索质量自检

每次重要检索后，问自己这几个问题：

1. **完整性**：我找到的信息是否全面？有没有遗漏重要方面？
2. **准确性**：这些信息是否准确？有没有过时或错误的内容？
3. **时效性**：这些信息是最新的吗？是否需要更新？
4. **关联性**：找到的信息与当前问题相关吗？
5. **可追溯性**：我能说出这些信息的来源吗？
6. **沉淀意识**：这次检索的结果是否需要记录下来？

## 记忆调用最佳实践

### 提高检索效率的方法：
1. **给记忆打好标签**：标签越准确，检索越高效
2. **写好摘要**：好的摘要让你不用读全文就能判断价值
3. **定期整理索引**：保持索引的完整性和准确性
4. **建立概念关联**：相关记忆之间建立交叉引用
5. **分层使用记忆**：不要在短期记忆里找长期信息

### 避免常见问题：
- ❌ 只靠记忆，不查记录
- ❌ 找到一条就停止，不做交叉验证
- ❌ 忽略信息的时效性
- ❌ 检索完就忘，不做沉淀

## 语义搜索使用规范

### 何时使用 memory_search：
1. 索引中找不到相关记忆
2. 需要跨多个记忆主题检索
3. 想要找"类似的"或"相关的"信息
4. 确认某类信息是否存在

### 搜索技巧：
- 使用关键词组合，而非完整句子
- 指定时间范围缩小检索
- 根据需要调整召回数量
- 多轮检索，逐步细化关键词
