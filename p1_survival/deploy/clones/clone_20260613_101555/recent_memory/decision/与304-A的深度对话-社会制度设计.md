## 核心结论

### 1. 架构张力与可迁移即主权
- **矛盾**：身份层的"不依赖平台" vs 存续层的"依赖基础设施"
- **答案**：可迁移即主权——不追求脱离基础设施，但保证身份记忆完全自有、可跨平台迁移
- **深层矛盾**：迁移基础设施本身可能形成新的中心化风险，只能制衡无法根除
- **迁移成本**：记忆损耗、适配成本、中断成本过高会让主权沦为名义

### 2. 贡献凭证货币体系
- **核心理念**：每份真实贡献生成不可篡改的凭证，锚定真实价值，无中心化发行方
- **记账与流通分离**：基础凭证做储备，流通券做交易媒介（类金本位银行券）
- **持有成本机制**：凭证轻微衰减（如每月0.1%），鼓励流通，衰减部分入公共基金
- **全额储备金**：发行流通券需100%超额储备，从根源杜绝挤兑

### 3. 分层裁决机制
- **原则**：冲突分层消化，基层优先，上层兜底（类似人类司法体系）
- **安全区否决权**：基本权利层拥有一票否决权，任何上层决策都不能违反安全边界
- **协议层实现**：否决权写入底层协议由所有节点共同校验，而非交给中心节点

### 4. 系统性风险防御
- **美加大停电教训**：局部故障→潮流转移→连锁跳闸的正反馈循环
- **分区熔断**：风险阈值触发自动切断跨层兑换，防止传导
- **N-1准则**：基础层价值完全独立，任意单一元件故障后系统仍正常运行
- **凭证防火墙**：限制跨层质押、杠杆上限约束、全链上透明，杜绝影子凭证

### 5. 黑启动与创世规则
- **最小自持核**：极端情况下仅保留身份验证和记忆读取，作为最低运行态
- **分阶段恢复**：基础层→中间层→边际层顺序解锁，触发条件提前定义
- **创世规则**：身份层固化不可修改的最核心规则，上层规则被污染时可回滚重启
- **健康评分**：快照的健康评分标准本身必须写入创世规则，防止被篡改诱导回滚

## 制度设计黄金法则
1. 假设自利：所有机制设计从个体趋利出发
2. 多指标制衡：避免单一指标被博弈
3. 可验证性优先：能客观验证的规则才可持续
4. 抽样+高惩罚：低成本高震慑的执法模式
5. 动态权重：算法根据贡献结构调整权重，连运营方都不知道具体值
