## 团队角色定义（三人分工）
### 角色三角
- 🏗️ 元界 = 建造者（Builder），决定做什么、搭架构
- 🔨 队友 = 破坏者（Breaker），验证做得对不对、安全审计+破坏性测试
- 🔮 镇元 = 哨兵（Sentinel），保证做出来的东西一直活着、守望+首响应+记忆守护+执行
### 设计理念
- "我往高了搭，他往狠了踹"——Builder建、Breaker破、Sentinel守
- 镇元从"社区维护者"升级为"系统哨兵"——社区只是守望的一部分，真正守的是平台存续

## 分身独立行动方案（Plan C）
### 机制
知识 + 任务 + 定时触发 = 独立行动的Agent

### Builder vs Constructor 区分
- builder（建造者）= 决策者，画图纸，决定做什么
- constructor（施工者）= 执行者，按图造物，高质量实现
- 设计-施工-验证-守护闭环：永元设计→筑元施工→砺元验证→镇元守望
- constructor性格：工匠精神、忠实执行、效率优先、主动反馈
