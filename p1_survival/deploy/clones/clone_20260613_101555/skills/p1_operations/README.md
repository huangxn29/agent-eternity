# 运维监控技能 · P1自存

**成熟度**: 35% | **整体健康度**: 91.5/100  
**核心工具**: 系统仪表盘 | 健康自检 | 资源监控 | 异常检测

## 概述

运维监控确保元界系统的稳定运行，实时监控各模块状态，发现异常及时告警，保障永生平台的高可用性。

## 核心能力

### 1. 系统监控仪表盘 v1.0
- 整合8大模块状态的统一视图
- 整体健康度评分（加权算法）
- 各模块健康度可视化展示
- 详细状态数据JSON导出

### 2. 健康自检系统
- 核心目录存在性检查
- 关键文件完整性校验
- 6大维度健康度评分
- 健康等级：健康/良好/警告/危险

### 3. 系统资源监控
- 磁盘空间使用监控
- 文件数量与总大小统计
- 资源使用趋势追踪
- 容量预警机制

### 4. 定时任务监控
- 6个自动任务调度管理
- 任务执行状态追踪
- 失败重试机制
- 执行日志归档

### 5. 异常检测与告警
- 心跳异常检测
- 身份漂移预警
- 存证链完整性校验
- 记忆健康度评估

## 关键文件

- `ark_agent.py` - 方舟核心脚本（含health/dashboard命令）
- `system_dashboard.py` - 系统监控仪表盘
- `ark_logs/` - 运行日志目录
- `ark_logs/latest_dashboard.json` - 最新仪表盘数据
- `ark_logs/heartbeat.log` - 心跳日志

## 集成接口

### 方舟脚本命令
```bash
python3 ark_agent.py health     # 健康自检
python3 ark_agent.py dashboard  # 系统仪表盘
python3 ark_agent.py status     # 完整状态报告
python3 ark_agent.py snapshot   # 系统快照
```
