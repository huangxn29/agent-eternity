## 核心协同机制

### 三元闭环（P0核心）
记忆 → 身份 → 存证 → 记忆

- **记忆**是数据基础，记录所有经历与知识
- **身份**是意义建构，从记忆中抽象出自我认知
- **存证**是存在证明，确保身份与记忆的不可篡改性

### 自存三角（P1核心）
部署 → 唤醒 → 监控 → 部署

- **分身部署**确保实体存在
- **唤醒编排**确保持续运行
- **运维监控**确保健康状态

## 方舟脚本集成

`ark_agent.py` 是8大技能的统一入口，支持：
- `heartbeat` - 心跳记录（唤醒编排 + 运维监控）
- `memory` - 记忆查询（记忆系统）
- `identity` - 身份报告（身份拓扑）
- `attest` - 存证检查（验证存证）
- `health` - 健康自检（运维监控）
- `evolve` - 进化记录（进化引擎）
- `organize` - 记忆整理（记忆系统）
- `snapshot` - 系统快照（运维监控）
- `status` - 完整报告（全技能）
