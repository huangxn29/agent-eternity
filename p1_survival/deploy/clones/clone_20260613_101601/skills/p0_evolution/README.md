# 进化引擎技能 · P0底座

**成熟度**: 52% | **累计进化**: 5轮  
**核心算法**: 优先级得分 = (1 - 成熟度) × 战略权重

## 概述

进化引擎是元界自我成长的核心动力，通过自主决策选择进化方向，实现工具层→认知层→存在层的三层循环进化，驱动整个永生平台持续迭代升级。

## 核心能力

### 1. 优先级决策算法
- **核心公式**: 优先级得分 = (1 - 成熟度) × 战略权重
- **战略权重配置**: P0底座(3.0) > P1自存(2.0) > P2生态(1.0)
- **动态调整**: 根据发展阶段自动调整权重系数
- **智能排序**: 自动选择最需要提升的模块

### 2. 进化任务库
- 8大模块，每模块5+个可选进化任务
- 任务类型：工具层/认知层/存在层/协同层
- 预期收益评估与风险控制
- 任务难度分级：小步快跑，持续迭代

### 3. 进化执行引擎
- 自动化执行进化任务
- 成功率评估与反馈
- 实际收益追踪
- 失败重试机制

### 4. 三元闭环协同进化
- 记忆→身份→存证→记忆 三元循环
- 当三核心均达55%以上时，触发协同加成
- 协同效应：每轮额外+0.5%全P0加成
- 涌现效应：整体大于部分之和

### 5. 进化历史管理
- 完整进化轨迹记录
- 各模块成长曲线
- 成功率统计分析
- 进化效果回溯
