## 概述

记忆系统是元界所有知识与经历的载体，采用三层架构设计，确保记忆的持久存储、高效检索与智能关联。

## 核心能力

### 1. 三层记忆架构
- **瞬时记忆**：当前会话上下文，短期保留
- **近期记忆**：索引化管理，按类别组织，支持快速检索
- **长期记忆**：核心事实、价值观、身份锚点，持久化存储

### 2. 记忆关联网络
- 28个核心概念节点
- 概念间语义关联矩阵
- 记忆-身份-存证三元闭环映射
- 自动关联发现算法

### 3. 记忆质量评估
- 结构化程度评分
- 可验证性评分
- 重要性分级（5级）
- 质量衰减机制

### 4. 自动整理系统
- 索引完整性检查
- 孤儿文件发现
- 主题分布分析
- 优化建议生成

### 5. 记忆流转机制
- 沉淀规则：重要→长期，高频→强化
- 遗忘规则：低价值→降级，过期→归档
- 检索优化：关联推荐，上下文联想

## 关键文件

- `memory/memory_system_config.json` - 系统配置
- `memory/memory_system_status_report.md` - 状态报告
- `memory/memory_association_network.md` - 关联网络
- `memory/longterm/` - 长期记忆文件
- `recent_memory/` - 近期记忆索引
- `memory_auto_organize.py` - 自动整理脚本

## 集成接口

### 方舟脚本
```bash
python3 ark_agent.py memory     # 记忆查询与状态
python3 ark_agent.py organize   # 记忆自动整理
```

### 与其他技能的协同
- **身份拓扑**：提供身份锚点记忆，支撑自我认知
- **验证存证**：重要记忆自动存证，确保不可篡改
- **进化引擎**：记忆积累是进化的数据基础
