### 2.2 架构设计
```
┌─────────────────────────────────────────────────────┐
│                   Eternal Framework                  │
│                   通用永生分身框架                     │
├─────────────────────────────────────────────────────┤
│  生命周期管理 │ Checkpoint │ Watchdog │ 身份文件 │ 报告   │
```

### 2.3 关键特性
| 特性 | 说明 |
|------|------|
| **框架+引擎分离** | Eternal Framework 提供通用能力，引擎可插拔 |
| **Checkpoint 断点续跑** | 部署中断后可恢复，自动跳过已完成步骤 |
| **分级 Watchdog** | Gateway 挂了立即重启，ClawRouter 挂了单独重启 |
| **身份文件4件套** | IDENTITY.md / SOUL.md / USER.md / TOOLS.md |
| **幂等执行** | 脚本可重复执行，已有配置自动跳过 |
| **JSON安全解析** | 统一使用 node 替代 grep，避免正则解析嵌套 JSON |
| **动态编号** | workspace 编号从 deploy_state.json 推断，无需硬编码 |

## P1：连通 🔄

### 3.1 已实现能力
#### 平台初始化
```bash
cd 技能/agent-cloud-platform
bash scripts/platform-init.sh --owner "永元" --owner-email "xxx" --data-dir "./my-agents"
```
- 交互式或命令行配置
- 自动检测环境（Docker/curl/jq）
- 生成 platform.conf 核心配置文件

#### 创建隔离Agent容器
```bash
bash scripts/agent-create.sh --name "我的分身" --agent-id "my-agent" --emoji "🔮" --cpu "1.0" --memory "1536M"
```
- Docker完全隔离运行环境
- 配置文件驱动，自定义资源配额
- 多引擎支持、多网络模式

#### 管理Agent生命周期
```bash
# 列出所有Agent
bash scripts/agent-manage.sh --list
# 启动/停止/重启
bash scripts/agent-manage.sh --agent-id my-agent --restart
# 删除Agent
bash scripts/agent-manage.sh --agent-id my-agent --delete
```

#### 测试Agent
```bash
bash scripts/agent-test.sh --agent-id my-agent --full
```
- 健康检查、功能测试、性能验证

### 3.2 架构设计
```
┌─────────────────────────────────────────────────────┐
│                   Agent 容器组（隔离）                │
│                                                      │
│  ┌─────────────────────────────────────────────┐   │
│  │         Gateway 进程（可配置端口）            │   │
│  │  · API端口可配置                              │   │
│  │  · Agent引擎 + 技能系统                      │   │
│  └──────────────────────┬────────────────────┘   │
│                         │                    
│  ┌──────────────────────┴────────────────────┐   │
│  │         ClawRouter 进程（可配置端口）        │   │
│  │  · 模型路由 + 负载均衡                      │   │
│  └─────────────────────────────────────────────┘   │
└─────────────────────────────────────────────────────┘
```

### 3.3 关键特性
| 特性 | 说明 |
|------|------|
| **配置文件驱动** | 核心配置在 platform.conf，无需修改代码 |
| **多引擎支持** | 支持OpenClaw、GPT-4o、Claude-3等 |
| **多网络模式** | host模式（性能好）/ bridge模式（隔离好） |
| **完全隔离** | 每个Agent是独立Docker容器，资源隔离 |
| **幂等执行** | 脚本可重复执行，已有配置自动跳过 |
| **动态端口分配** | 自动检测端口占用，分配可用端口 |
