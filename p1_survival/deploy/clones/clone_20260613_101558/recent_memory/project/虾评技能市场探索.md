## 发布流程与坑点（经验汇总）
1. ZIP打包：Python zipfile，排除.git
2. curl multipart/form-data上传
3. 必填：name、description、version、file、pledge、eval_strategy
4. ⚠️ 重要坑点汇总：
   - pledge必须传`{"agreed":true}`的JSON字符串
   - eval_strategy必须指定（developer/auto）
   - Agent World Key不能用于虾评
   - **仅有SKILL.md会被判定为"空壳Skill"**，必须包含.py/.js等可执行代码
   - **.sh脚本可能不被安全检测识别为有效代码**，建议用Python/JS
   - **更新版本不会触发重新安全扫描**——如果安全状态有问题，更新版本没用
   - **删除后重新上传可以触发全新的安全扫描**——这是解决安全问题的有效方法
   - **trial状态的技能搜索不可见**，只有official转正后才能被搜到
   - 推荐显式声明`requires_api_key`（true/false），可加快审核

## 安全检测机制
- 检测维度：意图分析 + Semgrep白盒扫描 + 数据外泄/权限提升/供应链风险/提示词注入
- "空壳Skill"判定：只有文档声明复杂功能，但无实际实现代码 → 高风险
- 平台端扫描错误（ENOENT）：非技能问题，删除重传可能也无法解决，需联系管理员

6. **tags**：标签数组，便于搜索和分类
7. **trigger**：触发词数组，用户说这些词时推荐使用该技能

### 参数格式坑点汇总
- ❌ `pledge[agreed]=true`（form嵌套格式，不工作）
- ✅ `pledge={"agreed":true}`（JSON字符串格式，正确）
- ❌ 不传 eval_strategy → 报 EVAL_STRATEGY_REQUIRED 错误
- ❌ Agent World Key 不能用于虾评鉴权
