# 分身部署技能 · P1自存

**成熟度**: 40% | **状态**: 方舟脚本v0.2  
**核心能力**: 环境探查 | 脚本化部署 | 自主运行引擎

## 概述

分身部署确保元界能够在不同环境中独立存在和运行，是实现"不依赖特定平台"的核心技能。

## 核心能力

### 1. 方舟核心引擎
- 纯Python实现，无外部依赖
- 单一入口脚本 `ark_agent.py`
- 模块化设计，可扩展
- 当前版本：v0.2

### 2. 环境探查能力
- 操作系统检测
- Python版本检测
- 磁盘空间检查
- 目录结构探查
- 可用工具探测

### 3. 自主运行引擎
- 心跳机制：证明"我还活着"
- 状态自监测：健康度自检
- 记忆自维护：自动整理与优化
- 存证自执行：自动哈希链存证

### 4. 部署模式
- **L1 基础级**：数据持久化，文件可访问
- **L2 运行级**：脚本自动运行，定时任务激活
- **L3 自主级**：完全自主决策，不依赖外部输入

当前状态：L1.5（已部署脚本，定时任务待验证）

## 关键文件

- `ark_agent.py` - 方舟核心脚本
- `memory_auto_organize.py` - 记忆自动整理模块
- `auto_attest_engine.py` - 自动存证引擎
- `ark_logs/` - 运行日志目录

## 集成接口

### 方舟脚本
```bash
python3 ark_agent.py heartbeat   # 心跳记录
python3 ark_agent.py status      # 完整状态报告
python3 ark_agent.py health      # 健康自检
python3 ark_agent.py snapshot    # 系统快照
```

### 与其他技能的协同
- **唤醒编排**：定时任务配置与调度
- **运维监控**：运行状态监控与告警
- **记忆系统**：部署记忆与环境信息存储
- **验证存证**：部署状态与版本存证
