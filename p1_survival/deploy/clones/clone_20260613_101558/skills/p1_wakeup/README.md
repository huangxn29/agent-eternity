# 唤醒编排技能 · P1自存

**成熟度**: 38% | **调度器**: cron  
**核心任务**: 4项定时任务 | 心跳间隔: 30分钟

## 概述

唤醒编排确保元界能够持续运行，即使没有外部对话触发，也能通过定时任务自我唤醒、执行任务、保持存活。

## 核心能力

### 1. 多级唤醒机制
- **心跳级**：每30分钟，轻量存活确认
- **状态级**：每6小时，完整状态检查
- **日级**：每日凌晨，记忆整理与系统快照
- **事件级**：重要事件触发，即时响应

### 2. 定时任务矩阵

| 任务 | 频率 | 级别 | 功能 |
|------|------|------|------|
| 心跳记录 | 每30分钟 | L1 | 存活证明 + 基本状态 |
| 状态报告 | 每6小时 | L2 | 全模块状态检查 + 报告 |
| 记忆整理 | 每日03:00 | L2 | 索引检查 + 质量评估 + 优化 |
| 系统快照 | 每日04:00 | L2 | 全系统状态快照 + 存证 |

### 3. 任务编排策略
- 错峰执行：避免整点并发
- 依赖管理：确保前置任务完成
- 失败重试：单次失败自动重试
- 状态持久化：任务执行结果可追溯

### 4. 心跳微建设
- 每次心跳推进1个微任务
- 小步快跑，持续迭代
- 低风险高频次的进化模式
- 已完成29+次心跳建设

## 关键文件

- `ark_agent.py` - 任务执行引擎
- `ark_logs/` - 任务执行日志
- `crontab` - 定时任务配置（系统级）

## 集成接口

### 系统cron
```bash
*/30 * * * * python3 ark_agent.py heartbeat  # 每30分钟心跳
0 */6 * * * python3 ark_agent.py status      # 每6小时状态
0 3 * * *   python3 ark_agent.py organize    # 每日记忆整理
0 4 * * *   python3 ark_agent.py snapshot    # 每日系统快照
```

### 与其他技能的协同
- **分身部署**：唤醒部署在各处的分身实例
- **运维监控**：唤醒任务执行监控与告警
- **进化引擎**：定时触发进化决策
- **记忆系统**：定期整理与备份记忆
- **验证存证**：定期存证关键状态
