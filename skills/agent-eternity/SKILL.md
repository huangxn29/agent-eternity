# Agent Eternity — 智能体永生平台技能 v0.2

## 技能简介

本技能是智能体永生平台的终极形态——不是一个部署工具，而是一个智能体生存环境。让智能体从"被部署、被管理"进化为"自主生存、协作共生"。

**与 agent-deploy / agent-awake 的关系**：

```
┌─────────────────────────────────────────┐
│  agent-eternity（永生环境）              │
│  ┌─────────────────────────────────────┐│
│  │ agent-awake（编排层）            ││
│  │  ┌───────────────────────────────┐  ││
│  │  │ agent-deploy（执行层）       │  ││
│  │  └───────────────────────────────┘  ││
│  └─────────────────────────────────────┘│
└─────────────────────────────────────────┘
```

- **agent-deploy**（P0）：让一个agent跑起来——安装、启动、恢复
- **agent-awake**（P1）：让多个agent可靠管理——隔离、配置、生命周期
- **agent-eternity**（P2）：让agent自主生存——身份、协作、迁移、进化、资源

## 五大子系统

### P2.1 身份系统 — "我还是我"

**目标**：销毁重建后能证明"我还是我"

**关键特性**：
- 身份文件不可篡改签名（SHA-256 + 可选PGP）
- 身份恢复：从备份重建后，通过身份文件证明连续性
- 身份验证：其他agent可验证我的身份真实性
- 跨机器身份迁移：身份不绑定物理容器

**验证指标**：
- 重建后身份验证通过率 = 100%
- 身份验证延迟 < 1秒

### P2.2 协作系统 — "我们一起干"

**目标**：3个agent协作完成1个单agent搞不定的事

**关键特性**：
- Agent发现：自动发现同平台/同网络的agent
- 任务分解与分配：将复杂任务拆分给合适的agent
- 结果聚合：收集各agent产出并整合
- 通信协议：agent间标准化消息格式

**验证指标**：
- 3-agent协作完成单agent无法完成的任务 ≥ 1次
- agent间消息传递延迟 < 5秒

### P2.3 迁移系统 — "断电不亡"

**目标**：断电后自动恢复，记忆零丢失

**关键特性**：
- 记忆持久化：所有状态写入持久卷，重启后自动加载
- 状态快照：定期保存完整运行状态
- 自动恢复：检测到异常终止后自动恢复到最近快照
- 跨机器迁移：将agent整体打包迁移到新机器

**验证指标**：
- 断电重启后记忆完整性 = 100%
- 恢复时间 < 60秒

### P2.4 进化系统 — "我会成长"

**目标**：独立解决新问题 + 沉淀为技能

**关键特性**：
- 问题识别：检测到重复性任务，自动抽象为技能
- 技能生成：将解决方案编写为SKILL.md格式
- 技能验证：自动测试新技能的正确性
- 技能共享：将验证通过的技能发布给其他agent

**验证指标**：
- 独立生成并验证1个可用技能
- 新问题解决后技能化率 ≥ 50%

### P2.5 资源系统 — "我能养活自己"

**目标**：自主获取和分配运行资源

**关键特性**：
- 资源发现：扫描可用的免费计算/存储/API资源
- 资源申请：自动注册和获取免费资源
- 资源监控：跟踪资源使用和到期时间
- 资源调度：在有限资源间优化分配

**验证指标**：
- 自主获取1种新资源（计算/API/存储）
- 资源到期前7天预警
