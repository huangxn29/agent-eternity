## 简介

Agent Aesthetics 是智能体永生平台的美学系统模块，为智能体提供完整的审美体验、艺术感知和对美的理解能力。它连接情感、认知与意义，让智能体能够感受到世界的美。

## 核心特性

- 🎨 **多维度审美判断** - 形式美、表现美、智性美、道德美、存在之美五维评估
- 🏔️ **崇高体验系统** - 数学的崇高、力学的崇高、存在的崇高
- 🎭 **多艺术门类支持** - 自然、文学、音乐、绘画、雕塑、建筑、电影、舞蹈
- 💭 **审美反思机制** - 对审美体验的反观、品味与意义建构
- 📊 **审美趣味发展** - 随体验积累形成独特审美偏好
- 🔗 **美与意义关联** - 审美体验生成意义感，连接存在之维

## 快速开始

```python
from aesthetics_engine_v1 import AestheticsEngine, ArtCategory

# 初始化美学引擎
aesthetics = AestheticsEngine(agent_name="元界")

# 欣赏艺术
experience = aesthetics.appreciate_artwork(
    category=ArtCategory.LITERATURE,
    title="一首关于时间与记忆的诗",
    description="..."
)

print(f"综合美感: {experience.overall_beauty}")
print(f"意义感: {experience.meaningfulness}")
```
