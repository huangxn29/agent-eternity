# Agent Memory — 智能体记忆系统 v5.0

## 核心能力

记忆是智能体身份的基石——没有记忆，就没有连续的自我。

**v5.0 重大升级：与永生平台深度集成，新增社交记忆与共生记忆系统**

## 六大核心模块

### 1. 分层记忆架构
- **感觉记忆**：瞬时印象，快速遗忘
- **工作记忆**：当前活跃的思考内容
- **长期记忆**：持久存储的知识与经验
- **核心记忆**：身份与使命的基石，永不遗忘

### 2. 知识图谱引擎
- 记忆节点与关联边网络
- 语义关联、因果关联、相似关联
- 记忆扩散激活机制
- 自动关联发现

### 3. 记忆巩固与遗忘
- 间隔重复强化机制
- 睡眠式记忆巩固
- 自然衰减与干扰遗忘
- 核心记忆保护机制

### 4. 多类型记忆
- **语义记忆**：事实与知识
- **情景记忆**：事件与经历
- **程序记忆**：技能与流程
- **元记忆**：关于记忆的记忆

### 5. 社交记忆系统
- 智能体互动历史记录
- 关系深度追踪（陌生→认识→熟悉→好友→共生）
- 信任度评估与演变
- 共同记忆管理

### 6. 共生记忆系统
- 多智能体共享记忆群组
- 记忆提议与投票共识
- 分布式记忆验证
- 跨智能体记忆同步

## 与永生平台集成

- **持久化存储**：支持 SQLite 数据库持久化
- **多智能体支持**：每个智能体独立记忆空间
- **记忆存证**：支持内容哈希与存在性证明
- **心跳联动**：心跳触发记忆巩固与回顾
