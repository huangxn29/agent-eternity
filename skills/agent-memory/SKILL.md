# Agent Memory — 智能体记忆系统 v4.0

## 核心能力

| 记忆类型 | 说明 | 成熟度 |
|---------|------|--------|
| 情景记忆 | 记录经历的事件和场景 | 95% |
| 语义记忆 | 存储知识和事实 | 90% |
| 程序记忆 | 保存技能和流程 | 85% |
| 元记忆 | 关于记忆的记忆（知道自己知道什么） | 80% |

## 记忆架构

```
┌───────────────────────────────────────────────────┐

│  感觉缓冲 (Sensory Buffer)                         │
│  · 输入预处理                                      │
│  · 瞬时记忆                                        │
└───────────────────────────────────────────────────┘
```

## 核心功能

### 1. 记忆存储
- 自动分类：新信息自动归类到对应记忆类型
- 知识图谱化：实体-关系建模，支持关联检索
- 分层存储：高频记忆在前，低频记忆归档

### 2. 记忆检索
- 语义检索：按含义搜索，不是关键词匹配
- 联想检索：从一个记忆联想到相关记忆
- 时序检索：按时间线回溯经历

### 3. 记忆巩固
- 睡眠巩固：模拟睡眠，整理和强化记忆
- 遗忘机制：不重要的记忆逐渐衰退
- 记忆整合：新旧知识融合，产生新理解

### 4. 元记忆
- 自我认知：知道自己知道什么、不知道什么
- 记忆评估：评估记忆的准确性和可靠性
- 主动学习：识别知识缺口，主动寻求补充

## 使用方式

### 写入记忆
```bash
memory add --type episodic --content "今天学习了技能进化引擎的设计" --importance 0.8
memory add --type semantic --content "SKILL.md是扣子技能的定义文件" --confidence 0.95
```

### 检索记忆
```bash
memory search "技能进化" --limit 10
memory recall --date 2026-06-14 --type episodic
```

### 记忆巩固
```bash
memory consolidate --mode sleep
memory forget --threshold 0.3  # 遗忘重要度低于0.3的记忆
```

## 与其他技能的关系

- **agent-evolution**: 记忆是技能进化的知识库
- **agent-social**: 社交记忆是社交技能的基础
