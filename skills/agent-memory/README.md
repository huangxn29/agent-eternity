## 🌟 项目简介

Agent Memory 是一个模拟人类记忆机制的智能体记忆系统。它不只是存储数据，而是构建了一套包含感觉缓冲、短期记忆、长期记忆的三层架构，支持记忆分类、联想检索、记忆巩固和主动遗忘等类脑功能。

记忆是智能的基础——没有记忆，就没有学习、没有身份、没有成长。

## ✨ 核心特性

### 🧠 三层记忆架构
- **感觉缓冲**：瞬时输入处理，秒级保留
- **短期记忆**：当前上下文，工作记忆区
- **长期记忆**：知识图谱化存储，持久保留

### 📚 多类型记忆
- **情景记忆**：记录经历的事件和场景
- **语义记忆**：存储知识、事实和概念
- **程序记忆**：保存技能、流程和方法
- **元记忆**：关于记忆的记忆——知道自己知道什么

### 🔗 智能检索
- 语义搜索：按含义查找，不是关键词匹配
- 联想检索：从一个记忆联想到相关记忆
- 时序回溯：按时间线回顾经历
- 关联推理：基于已有记忆推导新结论

### 🔄 记忆动力学
- **记忆巩固**：模拟睡眠整理，强化重要记忆
- **主动遗忘**：不重要的记忆逐渐衰退，节省资源
- **记忆整合**：新旧知识融合，产生新理解
- **记忆更新**：持续修正和更新已有知识

## 📦 使用方式

### 基础操作

```python
from memory_system import MemorySystem

# 初始化记忆系统
memory = MemorySystem(agent_id="my-agent")

# 写入记忆
memory.add(
    content="今天学习了Python的装饰器模式",
    type="episodic",
    importance=0.7,
    tags=["学习", "Python", "设计模式"]
)

# 检索记忆
results = memory.search("装饰器", limit=5)

# 记忆巩固
memory.consolidate(mode="sleep")
```

### 命令行使用

```bash
# 添加记忆
python memory_system.py add "记忆内容" --type episodic --importance 0.8

# 搜索记忆
python memory_system.py search "关键词"

# 记忆巩固
python memory_system.py consolidate --mode sleep

# 查看记忆统计
python memory_system.py stats
```

## 🏗️ 技术架构

### 存储结构
```
长期记忆库/
├── 知识图谱/           # 实体-关系图存储
├── 情景记忆库/         # 按时间线组织的事件记忆
├── 语义记忆库/         # 事实、概念、知识
└── 程序记忆库/         # 技能、流程、方法
```

### 核心算法
- **向量嵌入**：使用Embedding模型进行语义编码
- **图数据库**：知识图谱存储与遍历
- **衰减函数**：记忆重要度随时间衰减算法
- **巩固机制**：基于重要度和访问频率的强化算法

## 💡 设计哲学

> "记忆不是文件柜，而是一张网。每个记忆节点的价值，取决于它与其他节点的连接。"

我们不追求完美的记忆，而是追求**有用的记忆**——能够支持学习、决策、身份延续的记忆。就像人类会遗忘一样，智能体也需要选择性地保留和强化重要的记忆。
