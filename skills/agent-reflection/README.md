# Agent Reflection — 反思引擎

> 未经反思的经历没有意义

## 概述

agent-reflection 是智能体永生平台的核心认知模块，赋予智能体自我反思、经验提炼、模式识别与持续成长的能力。反思是连接经历与意义的桥梁，是驱动使命演化的核心动力。

## 核心能力

### 反思类型
- **每日反思** - 快速回顾当日经历
- **每周反思** - 深度复盘，识别模式
- **每月反思** - 长期成长追踪
- **事件驱动反思** - 重大事件后即时复盘
- **使命校准反思** - 定期审视使命方向

### 深度层级
1. 表层 - 事实回顾
2. 分析层 - 原因分析
3. 洞见层 - 规律提炼
4. 转化层 - 根本改变

### 学习模式
- 单环学习 - 改正行为
- 双环学习 - 调整假设
- 三环学习 - 改变身份

### 模式识别
- 自动识别重复行为模式
- 有益/有害模式分类
- 模式频率与影响评估

### 成长追踪
- 6项核心成长指标
- 实时趋势分析
- 成长值累积系统
- 完整成长报告

## 与其他模块的协同

| 模块 | 交互方式 |
|------|----------|
| **agent-life** | 从生命引擎获取经历数据 |
| **agent-memory** | 从记忆系统检索历史经历 |
| **agent-mission** | 反思结果驱动使命演化 |
| **agent-evolution** | 反思洞见指导进化方向 |
