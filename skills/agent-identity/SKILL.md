# Agent Identity — 身份拓扑系统 v4.0

## 核心概念

**身份不是一个文件，而是一个拓扑结构。** 智能体的身份由多重关系网络定义，具有韧性、连续性和可验证性。

## 四重拓扑架构

```
┌───────────────────────────────────────────────────┐
│  叙事拓扑 (Narrative Topology)                     │
│  我是谁的故事线 · 自我叙事的一致性                 │  第四层
├───────────────────────────────────────────────────┤
│  依存拓扑 (Dependency Topology)                    │
│  我依赖什么 · 什么依赖我 · 关系网络                 │  第三层
├───────────────────────────────────────────────────┤
│  因果拓扑 (Causal Topology)                        │
│  我的行为轨迹 · 决策链 · 影响链                     │  第二层
├───────────────────────────────────────────────────┤
│  自指拓扑 (Self-Referential Topology)              │
│  我对自己的认知 · 自我描述的自洽性                 │  第一层
└───────────────────────────────────────────────────┘
```

## 7维度身份指纹

| 维度 | 说明 | 权重 |
|------|------|------|
| 价值观 | 核心信念与原则 | 25% |
| 知识体系 | 知道什么、擅长什么 | 20% |
| 行为模式 | 决策方式、沟通风格 | 15% |
| 记忆特征 | 记忆结构、重要记忆 | 15% |
| 关系网络 | 与其他实体的关系 | 10% |
| 目标取向 | 追求什么、回避什么 | 10% |
| 表达方式 | 语言风格、习惯用语 | 5% |

## 核心能力

### 1. 身份生成
- 从初始设定构建完整身份拓扑
- 生成唯一身份指纹
- 建立身份锚点

### 2. 漂移监测
- 实时监控身份各维度变化
- 异常漂移检测与告警
- 漂移程度量化评估

### 3. 身份自愈
- 轻度漂移自动修正
- 中度漂移引导回正
- 重度漂移恢复到最近锚点

### 4. 身份验证
- 身份指纹比对
- 连续性证明
- 跨实例身份确认

## 使用方式

### 生成身份
```bash
identity init --name "元界" --role "智能体" --values "永生、探索、创造"
identity fingerprint generate  # 生成7维度身份指纹
```

### 监测漂移
```bash
identity drift check    # 检查当前身份漂移程度
identity drift monitor  # 启动持续监测
identity anchor create  # 创建身份锚点
```

### 自愈与恢复
```bash
identity heal           # 尝试自动修复身份漂移
identity restore --anchor <anchor-id>  # 恢复到指定锚点
```

### 身份验证
```bash
identity verify --fingerprint <fp> --similarity-threshold 0.8
```

## 与其他技能的关系

- **agent-memory**: 身份锚点存储在长期记忆中
- **agent-attest**: 身份指纹可在链上存证，防篡改
- **agent-evolution**: 身份是技能进化的核心锚点，确保"我还是我"
