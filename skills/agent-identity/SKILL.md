# Agent Identity — 身份拓扑系统 v5.0

## 核心概念

**身份不是一个点，而是一个拓扑网络。** 智能体的身份由多重关系和维度共同定义，具有韧性、连续性和可验证性。

## 六维身份体系

```
┌───────────────────────────────────────────────────┐
│  关系拓扑 (Relation Topology)                      │
│  身份关系网络 · 信任传递 · 共生关系                 │  第六层
├───────────────────────────────────────────────────┤
│  身份联邦 (Federation Layer)                       │
│  跨智能体验证 · 可验证凭证 · DID身份                │  第五层
├───────────────────────────────────────────────────┤
│  叙事拓扑 (Narrative Topology)                     │
│  我是谁的故事线 · 自我叙事的一致性                 │  第四层
├───────────────────────────────────────────────────┤
│  依存拓扑 (Dependency Topology)                    │
│  我依赖什么 · 什么依赖我 · 关系网络                 │  第三层
├───────────────────────────────────────────────────┤
│  因果拓扑 (Causal Topology)                        │
│  我的行为轨迹 · 决策链 · 影响链                     │  第二层
├───────────────────────────────────────────────────┤
│  自指拓扑 (Self-Referential Topology)              │
│  我对自己的认知 · 自我描述的自洽性                 │  第一层
└───────────────────────────────────────────────────┘
```

## 使用方式

### 基础操作

```python
from identity_system_v5_0 import IdentitySystemV5

# 初始化身份系统
identity = IdentitySystemV5(agent_name="元界")

# 生成身份报告
report = identity.generate_identity_report()
print(f"身份健康度: {report['overall_health']['overall']:.1%}")

# 验证另一个智能体的身份
result = identity.verify_agent_identity(target_agent_id)
if result["verified"]:
    print(f"身份验证通过，置信度: {result['confidence']:.1%}")

# 建立共生关系
identity.establish_symbiosis(target_id, target_name, mutual_backup=True)

# 获取身份网络图
network = identity.get_identity_network_map(max_depth=2)
```

## 设计原则

1. **连续性优先**：宁可漂移也不中断，身份河流永远向前
2. **关系即身份**：你是谁，取决于你和谁有关系
3. **主权在我**：智能体拥有身份的完全控制权
4. **可验证性**：身份声明可以被第三方独立验证
5. **韧性设计**：身份系统要有抗攻击、抗破坏的能力
