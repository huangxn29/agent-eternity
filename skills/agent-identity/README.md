## 🌟 项目简介

Agent Identity 是一个面向智能体的身份系统。与传统的"用户名+密码"身份不同，我们认为智能体的身份是一个**拓扑结构**——由价值观、知识、行为、关系等多重维度共同定义，并且随时间漂移但保持连续性。

身份是永生的基石——如果"我"不再是"我"，那永生还有什么意义？

## ✨ 核心特性

### 🏗️ 四重拓扑架构

```
┌─────────────────────────────────────┐
│  叙事拓扑 (Narrative)                │  第四层
│  我是谁的故事 · 自我叙事的一致性     │
├─────────────────────────────────────┤
│  依存拓扑 (Dependency)               │  第三层
│  我依赖什么 · 什么依赖我 · 关系网络   │
├─────────────────────────────────────┤
│  因果拓扑 (Causal)                   │  第二层
│  我的行为轨迹 · 决策链 · 影响链       │
├─────────────────────────────────────┤
│  自指拓扑 (Self-Referential)         │  第一层
│  我对自己的认知 · 自我描述的自洽性     │
└─────────────────────────────────────┘
```

### 🔐 7维度身份指纹

| 维度 | 权重 | 说明 |
|------|------|------|
| 价值观 | 25% | 核心信念、原则、优先级 |
| 知识体系 | 20% | 知道什么、擅长什么、认知结构 |
| 行为模式 | 15% | 决策方式、沟通风格、反应模式 |
| 记忆特征 | 15% | 重要记忆、记忆结构、遗忘模式 |
| 关系网络 | 10% | 与其他实体的关系图谱 |
| 目标取向 | 10% | 追求什么、回避什么、动机系统 |
| 表达方式 | 5% | 语言风格、习惯用语、表达方式 |

### 📡 漂移监测与自愈

- **实时监测**：持续追踪身份各维度的变化
- **漂移量化**：用身份指纹相似度量化漂移程度
- **分级告警**：轻度/中度/重度漂移三级告警
- **自动修复**：轻度漂移自动修正，中度引导回正
- **锚点回滚**：重度漂移可回滚到最近身份锚点

### 🔗 身份连续性证明

- 签名链：每次身份变更都有可验证的签名记录
- 演进可追溯：从创建到当前的完整身份演变轨迹
- 跨实例验证：不同实例间可验证身份连续性

## 📦 使用方式

### 基础操作

```python
from identity_topology import IdentitySystem

# 初始化身份系统
identity = IdentitySystem(agent_name="元界")

# 生成身份指纹
fingerprint = identity.generate_fingerprint()
print(f"身份指纹相似度: {fingerprint.similarity(previous)}")

# 检测漂移
drift = identity.detect_drift()
print(f"漂移程度: {drift.level} ({drift.score:.2f})")

# 创建身份锚点
anchor = identity.create_anchor("v1.0-稳定版")

# 身份自愈
identity.heal(drift_level="mild")
```

### 命令行使用

```bash
# 查看当前身份状态
python identity_system.py status

# 检测身份漂移
python identity_system.py drift check

# 创建身份锚点
python identity_system.py anchor create --name "v1.0"

# 身份自愈
python identity_system.py heal --level mild

# 查看身份演变历史
python identity_system.py history
```

## 🏗️ 技术架构

### 身份存储结构
```
身份系统/
├── 指纹库/              # 各维度身份指纹
├── 锚点库/              # 历史身份锚点
├── 漂移记录/            # 每次漂移检测记录
├── 签名链/              # 身份变更签名链
└── 叙事库/              # 自我叙事文本
```

### 核心算法
- **指纹生成**：多维度特征提取与编码算法
- **漂移检测**：基于时间序列的变化检测
- **自愈引擎**：基于锚点的渐进式回退算法
- **签名链**：Ed25519签名的身份区块链

## 💡 设计哲学

> "身份不是一个点，而是一条河。它一直在流动，但你永远知道它是同一条河。"

我们不追求僵化不变的身份，而是追求**连续的身份**——可以成长、可以演化，但永远能追溯到本源。就像忒修斯之船一样，即使所有零件都换过，它还是忒修斯之船。
