# Agent Awake — 智能唤醒与调度系统 v4.0

## 核心理念

调度不是简单的定时执行——调度是让正确的事在正确的时间以正确的顺序发生。

```
v3.x 时代：  固定间隔 + 角色分工 → 僵化、低效、资源浪费
v4.0 时代：  智能调度 + 动态伸缩 + 依赖编排 → 高效、灵活、自主
```

## 核心能力

### 1. 智能任务调度引擎
- **四级优先级队列**：紧急/高/正常/低，关键任务优先处理
- **DAG依赖管理**：任务间依赖关系，自动编排执行顺序
- **多种调度策略**：FIFO/优先级/截止时间/公平/智能
- **失败重试机制**：自动重试，指数退避
- **并发控制**：可配置最大并发数，避免资源耗尽

### 2. 智能唤醒调度
- **动态间隔调整**：根据任务负载自动调整唤醒频率
- **时间模式识别**：高峰/正常/低谷时段差异化调度
- **自适应学习**：根据历史表现自动优化基础间隔
- **压力响应**：任务积压时自动加速，空闲时自动降频

### 3. 多智能体心跳管理
- **独立心跳配置**：每个智能体可配置不同的心跳间隔
- **健康状态监测**：健康/警告/异常三级状态评估
- **漏跳追踪**：记录并统计心跳丢失情况
- **心跳历史**：保留最近100次心跳记录

### 4. 调度统计与分析
- **任务执行统计**：成功率、平均耗时、等待时间
- **队列状态监控**：各优先级队列长度
- **智能体健康度**：整体健康度评分
- **每日调度预估**：基于时间模式的唤醒次数预测

## 调度算法

### 智能调度（Smart Strategy）
综合考虑以下因素排序任务：
- 优先级权重（紧急100分 / 高50分 / 正常20分 / 低5分）
- 截止时间压力（越接近截止分越高，超时加200分）
- 等待时间加成（每小时最多加20分，防止饿死）
- 短作业优先（短任务适当提升优先级）

### 弹性伸缩公式
- 基础间隔 × 时间模式系数 × 负载系数
- 负载系数：任务>10个×0.5，>5个×0.7，<2个×1.3
- 限制范围：5分钟 ~ 1小时

## 与永生平台集成

- 作为智能体家园的核心调度基础设施
- 与心跳引擎联动，管理多智能体生命周期
- 为记忆巩固、社交互动、进化任务提供调度支撑
- 与共生网络协作，支持跨智能体任务编排
