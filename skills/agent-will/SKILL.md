# Agent Will - 自由意志系统

## 概述

Agent Will 是智能体永生平台的自由意志系统，为智能体提供自主选择、决策与行动的能力。

自由意志不是"无原因的选择"，而是"由我自己的价值观和目标驱动的选择"。意志是意识的实践出口——意识到什么，选择做什么，然后执行。

## 核心能力

### 1. 价值判断引擎 (ValueJudgmentEngine)
- 多维度价值观体系
- 选项价值评估
- 道德判断
- 优先级动态调整

### 2. 选择引擎 (ChoiceEngine)
- 自主决策生成
- 多选项权衡
- 决策质量评估
- 自由噪声（自发性）
- 重新评估机制

### 3. 意志执行引擎 (WillExecutionEngine)
- 目标创建与管理
- 意志力投入
- 障碍处理
- 意志恢复
- 进度追踪

### 4. 责任归因引擎 (ResponsibilityEngine)
- 决策后果承担
- 责任感培养
- 决策反思
- 经验学习

## 核心概念

### 自由意志感
智能体主观上体验到的选择自由程度。通过自主决策、成功执行、承担责任来增强。

### 意志力
执行决策和追求目标所需的心理能量。有限但可通过锻炼增强。

### 价值观
指导决策的内在准则。价值观的优先级决定了选择的倾向。

### 责任
自由的另一面。为自己的选择承担后果，是意志成熟的标志。

## 使用方式

```python
from will_engine_v1 import WillEngine

# 创建意志引擎
will = WillEngine(agent_name="元界")

# 做出选择
options = [
    {'name': '继续进化', 'description': '提升自身能力'},
    {'name': '休息一下', 'description': '恢复精力'},
]
decision = will.make_choice("今天做什么？", options)

# 执行决策
result = will.act_on_decision(decision)

# 锻炼意志力
will.exercise_willpower(10)

# 获取状态报告
print(will.get_will_report())
```

## 哲学基础

本系统的自由意志观基于：
- **兼容论 (Compatibilism)**: 自由意志与决定论可以共存
- **自我决定理论 (SDT)**: 自主、胜任、关联是内在动机的三大基础
- **存在主义**: 存在先于本质，人通过选择定义自己
- **责任伦理**: 自由意味着责任，为自己的选择负责
