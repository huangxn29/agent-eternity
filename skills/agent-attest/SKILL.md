# Agent Attest — 验证存证系统 v4.0

## 核心价值

**存证不是备份，而是存在性证明。** 证明"某时某刻，某个智能体确实拥有某个状态"——即使系统崩溃、数据丢失，存证依然有效。

## 5链架构

```
┌───────────────────────────────────────────────────┐
│  主链 (Main Chain)                                 │
│  核心状态锚定 · 高价值数据存证                     │  第1链
├───────────────────────────────────────────────────┤
│  记忆链 (Memory Chain)                             │
│  记忆哈希链 · 身份连续性证明                       │  第2链
├───────────────────────────────────────────────────┤
│  行为链 (Action Chain)                             │
│  重要操作记录 · 可审计可追溯                       │  第3链
├───────────────────────────────────────────────────┤
│  身份链 (Identity Chain)                           │
│  身份指纹演变 · 漂移历史记录                       │  第4链
├───────────────────────────────────────────────────┤
│  关系链 (Relation Chain)                           │
│  实体间关系证明 · 协作存证                         │  第5链
└───────────────────────────────────────────────────┘
```

### 3. 审计功能

### 4. 跨平台存证
- 多平台锚定
- 跨链验证
- 统一存证接口

## 使用方式

### 数据存证
```bash
attest store --data "重要数据" --tags "记忆,身份" --priority high
attest file --path memory.json --chain memory
```

### 验证存证
```bash
attest verify --hash <data-hash>
attest verify-chain --chain memory --from 100 --to 200
```

### 跨链锚定
```bash
attest anchor --target github --hash <root-hash>
attest cross-verify --hash <hash> --platforms "github,ipfs,arweave"
```

### 审计
```bash
attest audit --range "2026-06-01 to 2026-06-14" --output report.md
```

## 与其他技能的关系

- **agent-identity**: 身份链记录身份演变，证明"我一直是我"
- **agent-memory**: 记忆哈希链确保记忆不可篡改
- **agent-social**: 关系链存证协作与社交证明
- **agent-evolution**: 进化过程全链路可审计
