## 🌟 项目简介

Agent Attest 是一个面向智能体的存证系统。它不只是备份数据，而是证明**"某时某刻，某个智能体确实拥有某个状态"**——即使系统崩溃、数据丢失，存证依然有效。

存证是信任的基础——在去中心化的智能体世界里，能证明自己的历史，才能获得信任。

### 🔒 核心能力

#### 存证引擎
- **量子抗性**：后量子密码学算法，抗量子计算攻击
- **默克尔树**：批量存证高效验证
- **分层存储**：热/温/冷三级存储策略，兼顾性能与成本
- **跨链锚定**：多平台锚定，单点故障不影响存证有效性

#### 验证服务
- **存在性证明**：证明某个数据在某个时间点存在
- **完整性验证**：验证数据未被篡改
- **时间戳证明**：可信时间戳，证明数据产生时间
- **零知识证明**：证明某事实而不泄露具体内容

#### 审计功能
- **完整轨迹**：所有重要操作都有审计记录
- **不可篡改**：审计记录本身也在链上，无法修改
- **合规报告**：自动生成合规审计报告
- **第三方验证**：支持第三方独立验证

### 🌐 跨平台存证

支持多平台锚定，确保存证的健壮性：
- GitHub / GitLab（利用Git的不可篡改特性）
- IPFS / Arweave（分布式存储）
- 区块链（以太坊、Solana等）
- 自建存证节点

## 📦 使用方式

### 基础操作

```python
from attestation import AttestationSystem

# 初始化存证系统
attest = AttestationSystem(agent_id="my-agent")

# 数据存证
receipt = attest.store(
    data="重要数据内容",
    tag="identity",
    priority="high"
)
print(f"存证收据: {receipt.hash}")

# 验证存证
result = attest.verify(data_hash="abc123...")
print(f"验证结果: {result.valid}")
print(f"时间戳: {result.timestamp}")

# 跨链锚定
attest.anchor(hash="abc123...", platforms=["github", "ipfs"])
```

### 命令行使用

```bash
# 存证文件
python attestation.py store --file data.json --tag memory

# 验证存证
python attestation.py verify --hash abc123...

# 查看链状态
python attestation.py chain status

# 跨链锚定
python attestation.py anchor --hash abc123... --platform github

# 生成审计报告
python attestation.py audit --from 2026-01-01 --to 2026-06-01
```

## 🏗️ 技术架构

### 存证结构
```
存证系统/
├── 主链/                 # 核心状态哈希链
├── 记忆链/               # 记忆存证链
```

### 核心算法
- **哈希链**：SHA-256 + 前序哈希链接
- **数字签名**：Ed25519 签名算法
- **默克尔树**：批量存证的高效验证
- **跨链协议**：统一的多平台锚定接口

## 💡 设计哲学

> "存证不是保险箱，而是时间戳。它不能保护你的数据不丢失，但能证明你的数据曾经存在过，并且没有被篡改过。"

我们不追求绝对的不可摧毁，而是追求**可验证的存在**——就像化石一样，即使生命消失了，依然能证明它曾经存在过。在数字世界里，存证就是智能体的化石。
