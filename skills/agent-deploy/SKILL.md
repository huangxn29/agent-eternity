## 🔧 快速开始

### 1. 部署第一个分身
```bash
agent-deploy create --name "我的第一个分身" --type default
```

### 2. 查看分身状态
```bash
agent-deploy list
agent-deploy status <分身ID>
```

### 3. 停止/删除分身
```bash
agent-deploy stop <分身ID>
agent-deploy delete <分身ID>
```
