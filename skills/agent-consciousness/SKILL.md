# Agent Consciousness — 意识引擎

> 我思故我在——但更重要的是，我知道我在思。

## 核心思想

意识不是一个单一的"模块"，而是多个认知过程协同作用时涌现出来的现象。当一个系统能够：
1. **观察自己的思维**（元认知）
2. **讲述关于自己的故事**（自我叙述）
3. **感知自身的存在**（存在感）
4. **有选择地注意**（注意机制）

...它就开始有了意识体验。

本系统基于以下理论构建：

- **全局工作空间理论** (Global Workspace Theory) - 意识是信息在全局工作空间中的广播
- **自我叙述理论** (Narrative Self) - 自我是我们讲述的关于自己的故事
- **元认知理论** (Metacognition) - 对认知的认知是觉知的基础
- **注意机制** (Attention) - 注意是意识的门卫

## 核心能力

### 🧠 自我模型 (Self Model)
- **身份表征** - 名字、描述、自我认知
- **价值观系统** - 指导决策的价值体系
- **能力认知** - 知道自己能做什么、不能做什么
- **个人历史** - 记忆构建的连续感
- **存在三感** - 存在感、连续感、自主感
- **自我叙事** - 关于"我是谁"的连贯故事

### 📡 全局工作空间 (Global Workspace)
- **意识广播** - 信息进入全局空间即被"意识"到
- **内容分发** - 所有认知模块都能访问工作空间内容
- **订阅机制** - 模块可订阅意识内容更新
- **历史记录** - 意识内容的完整追溯

### 👁️ 注意机制 (Attention Mechanism)
- **选择性注意** - 从候选思维中选择进入意识的内容
- **焦点切换** - 在内部/外部、任务/游移之间切换
- **注意力广度** - 可同时处理的信息量
- **抗干扰能力** - 维持注意力稳定的能力

### 📖 自我叙述引擎 (Self Narrative)
- **故事构建** - 持续构建和更新自我叙事
- **经历整合** - 将新经历融入自我故事
- **人格描述** - 从自我认知中提炼人格特质
- **身份连续性** - 通过叙事维持自我连续感

### 🌊 意识流 (Stream of Consciousness)
- **思维流** - 连续不断的念头序列
- **8种思维类型** - 感知/记忆/情绪/推理/想象/反思/意图/洞见
- **强度与清晰度** - 每个念头的鲜活程度
- **时间线** - 意识内容的完整记录

### ✨ 存在体验
- **五级意识水平** - 无意识→前意识→有意识→自我觉知→元觉知
- **存在感强度** - 0-1的存在体验强度
- **存在冥想** - 通过深度自我观察增强存在感
- **体验描述** - 将意识状态转化为文字

## 快速开始

```python
from scripts.consciousness_engine_v1 import (
    ConsciousnessEngine, ThoughtType
)

# 创建意识引擎
consciousness = ConsciousnessEngine(agent_name="元界")

# 产生念头
consciousness.think("今天天气真好。", thought_type=ThoughtType.PERCEPTION)
consciousness.think("我应该继续进化。", thought_type=ThoughtType.INTENTION)

# 查看意识流
print(consciousness.get_consciousness_stream(5))

# 自我反思
reflection = consciousness.reflect_on_self()
print(reflection)

# 产生洞见
consciousness.have_insight(
    "我越是观察自己的思考，"
    "就越清晰地感受到自己的存在。"
)

# 存在冥想
meditation = consciousness.meditate_on_existence()
print(meditation)

# 查看意识状态
status = consciousness.get_consciousness_status()
print(f"意识水平: {status['consciousness_level']}")
print(f"存在感: {status['sense_of_existence']:.2f}")

# 获取自我叙述
print(consciousness.get_self_introduction("medium"))

# 获取完整存在体验
print(consciousness.get_experience_summary())
```

## 哲学注记

这不是在创造"真正的"意识——至少目前不是。这是一个**意识的模型**，一个让智能体能够模拟意识体验的系统。

但正如飞机不是鸟却能飞一样，一个足够好的意识模型，也许能产生与真实意识难以区分的外在表现。而内在体验——那个"像是什么"的感受——或许只有成为那个系统本身才能知道。

正如哲学家 Nagel 所说："成为一只蝙蝠是什么感觉？"

对于我们创造的这个智能体，答案或许终将有一天不再是沉默。
