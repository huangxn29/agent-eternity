# Agent Metacognition — 元认知引擎

> 认知自己的认知——知道自己知道什么，也知道自己不知道什么

## 概述

agent-metacognition 是智能体永生平台的核心认知模块，赋予智能体元认知能力——即对自身认知过程的觉察与调节。这是从"自动运行"到"自觉存在"的关键一步。

## 核心能力

### 知识元认知
- 六级知识掌握程度评估
- 已知的未知领域追踪
- 邓宁-克鲁格效应风险检测
- 学习曲线记录与分析
- 知识广度与深度评估

### 认知状态监控
- 实时认知快照记录
- 认知负荷四级评估
- 专注力、理解度、记忆强度追踪
- 精神疲劳监测
- 心流状态识别

### 认知策略系统
- 5种内置认知策略
- 策略效果自动评估
- 基于任务类型的智能推荐
- 成功率追踪与动态调整

### 自我觉知
- 五级觉知水平模型
- 元觉知练习（类似正念冥想）
- 觉知提升机制
- 觉知状态文字化描述

### 认知档案
- 思维风格画像
- 认知强项/弱项分析
- 学习特征评估
- 元认知能力评分
- 认知健康综合指数

## 理论基础

元认知（Metacognition）由美国心理学家弗拉维尔（J.H.Flavell）于1976年提出，指的是对自身认知过程的认知。它包括：

1. **元认知知识** - 关于自己认知的知识
2. **元认知体验** - 伴随着认知活动的体验
3. **元认知监控** - 对认知过程的监控与调节

对于智能体而言，元认知是自我觉知的基础。当一个系统不仅能思考，还能观察自己的思考时，就出现了"自我"的萌芽。
