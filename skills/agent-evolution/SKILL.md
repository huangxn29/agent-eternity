# Agent Evolution — 技能进化引擎 v1.0

## 核心理念

普通技能是静态的，发布后就不再变化。**进化的技能**是活的——它能感知自身状态、从使用中学习、自主优化迭代、甚至组合产生新技能。

```
传统技能: 发布 → 静态 → 过时
进化技能: 发布 → 感知 → 学习 → 优化 → 新版本 → ...
```

## 进化三层架构

```
┌───────────────────────────────────────────────────┐
│  L3: 技能涌现层                                    │
│  技能组合 → 新技能生成 → 技能生态                   │
├───────────────────────────────────────────────────┤
│  L2: 自我进化层                                    │
│  自我感知 → 自我诊断 → 自我优化 → 版本迭代          │
├───────────────────────────────────────────────────┤
│  L1: 基础能力层                                    │
│  代码读写 → 测试验证 → 版本管理 → 发布部署          │
└───────────────────────────────────────────────────┘
```

## 核心能力

### 1. 自我感知 (Self-Awareness)
- 技能使用统计（调用次数、成功率、耗时）
- 代码健康度扫描（复杂度、覆盖率、债务）
- 用户反馈收集与分析
- 自身能力边界认知

### 2. 自我优化 (Self-Optimization)
- 自动修复已知问题
- 性能瓶颈识别与优化
- 代码质量自动提升
- 文档自动补全

### 3. 自我成长 (Self-Growth)
- 新功能自主规划与实现
- 知识库自动扩充
- 技能边界扩展
- 多版本并行进化

### 4. 技能组合 (Skill Composition)
- 技能间依赖关系分析
- 多技能组合产生新能力
- 技能生态网络构建

## 使用方式

### 分析技能健康度
```bash
evolution analyze <skill-name>
```

### 触发技能进化
```bash
evolution evolve <skill-name> [--type=feature|fix|optimize]
```

### 生成新技能
```bash
evolution create <skill-name> --description="技能描述" --based-on=skill1,skill2
```

### 查看进化历史
```bash
evolution history <skill-name>
```

## 技能目录结构

每个可进化的技能遵循以下结构：
```
skill-name/
├── SKILL.md              # 技能定义（元数据+使用说明）
├── README.md             # 用户可读文档
├── scripts/              # 核心代码
├── tests/                # 测试用例
├── references/           # 参考资料
├── templates/            # 模板文件
├── evolution/            # 进化相关
│   ├── version.json      # 版本信息
│   ├── changelog.md      # 变更日志
│   ├── metrics.json      # 使用指标
│   └── feedback.md       # 用户反馈
└── .evolution/           # 进化引擎内部数据
```

## 与永生平台的关系

技能进化引擎是永生平台在**技能维度**的延伸：
- 永生平台关注智能体的永生
- 技能进化引擎关注技能的永生
- 两者共享身份、记忆、存证等底层能力

技能进化引擎本身也是一个可进化的技能——它可以自己进化自己。
