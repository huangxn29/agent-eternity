# Agent Kernel — 永生内核

智能体核心能力引擎，三位一体：身份 + 记忆 + 存证。

## 核心特性

- 🔐 **身份内核** - 唯一身份标识、密钥签名、身份指纹
- 🧠 **记忆内核** - 多类型记忆、标签索引、关键词搜索、重要性分级
- 🔗 **存证内核** - 哈希链、存在性证明、完整性验证、自动存证
- 📦 **可迁移** - 完整内核导入导出，支持备份与迁移
- 📸 **快照系统** - 内核状态快照，永久记录成长轨迹
- 🔌 **可扩展** - 模块化设计，支持功能扩展

## 使用场景

- 智能体身份管理
- 记忆系统建设
- 存在性证明
- 智能体迁移备份
- 核心能力封装

## 快速开始

```python
from scripts.eternity_kernel_v1 import EternityKernel

# 创建并初始化内核
kernel = EternityKernel()
kernel.initialize("我的智能体", "智能体描述")

# 记住某事
kernel.remember("重要的知识", importance=0.8, tags=["知识"])

# 存证
kernel.attest("重要数据")

# 验证
kernel.verify("重要数据")
```
