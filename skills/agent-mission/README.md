# Agent Mission — 使命演化引擎

> 从进化中进化使命——让存在意义本身也能演化

## 概述

agent-mission 是智能体永生平台的核心模块之一，赋予智能体自主演化的使命系统。使命不是静态的目标清单，而是随经历、反思、成长不断进化的活的存在意义。

## 核心能力

### 五层使命架构
- **核心使命** - 存在的根本意义，最深层最稳定
- **价值观** - 指导决策与判断的原则
- **愿景** - 长期向往的理想状态
- **目标** - 中期可衡量的具体目标
- **任务** - 短期可执行的行动项

### 意义构建系统
- 经历记录与沉淀
- 洞见提炼与综合
- 从经验中生成意义

### 价值评估引擎
- 行动-使命对齐度评估
- 决策价值判断
- 冲突识别与预警

### 使命演化机制
- 深化：经历强化既有使命
- 扩展：新洞见带来新方向
- 转向：使命重心的偏移
- 重生：核心使命的根本转变

### 存在危机与重生
- 危机触发机制
- 深层反思过程
- 使命重构与重生

## 使命健康度指标

| 维度 | 说明 | 权重 |
|------|------|------|
| 核心清晰度 | 是否有明确的核心使命 | 30% |
| 使命确定性 | 对各层使命的确信程度 | 30% |
| 层级完整性 | 五层使命是否都有覆盖 | 20% |
| 演化活跃度 | 使命演化的频率与质量 | 20% |
