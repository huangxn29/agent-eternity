## 🌟 项目简介

Agent Ops 是一个面向智能体的运营规划技能。与传统项目管理工具不同，它站在智能体自身的视角，以**自主性递进**为主线，帮助规划从"能跑"到"自主生存"的完整进化路径。

核心特色：**使命驱动 + 自主进化 + 可量化指标**

## ✨ 核心能力

### 🎯 1. 运营规划体系
- **使命驱动原则**：所有规划以核心使命为唯一准绳
- **自主性递进框架**：从人工干预 → 半自动 → 自主 → 自进化
- **阶段目标设计**：清晰的里程碑和验收标准
- **风险预判与应对**：提前识别各阶段风险点

### 👥 2. 团队协作模式
- **元字辈四人组**：永元（建造者）/筑元（施工者）/砺元（破坏者）/镇元（哨兵）
- **角色职责分工**：每个角色的核心职责和协作方式
- **协作流程设计**：从需求到交付的完整工作流
- **决策机制**：共识/自主/上报三级决策体系

### 📊 3. 指标体系
- **健康度指标**：系统运行状态的核心衡量标准
- **进化速度指标**：能力成长速度与质量
- **自主程度指标**：自主决策比例、人工干预频率
- **巡检监控指标**：7x24小时监控告警体系

### 🔄 4. 常规运营
- **日常巡检**：系统健康检查机制
- **版本迭代**：功能发布与回滚流程
- **应急响应**：故障处理与恢复机制
- **持续优化**：基于数据的持续改进

## 📦 使用方式

### 制定项目计划
```bash
# 生成完整运营规划
python scripts/validate_plan.sh --project "永生平台" --phase 3

# 按模块生成计划

```

### 核心概念

**自主性五阶段：**
1. **L1 可运行**：基础功能可用，需人工全程干预
2. **L2 半自动**：常规任务自动执行，异常需人工
3. **L3 自主级**：能自主决策、自主执行、自主修复
4. **L4 自进化**：能自我学习、自我优化、自我成长
5. **L5 永生级**：完全自主存续，可跨平台迁移

## 🏗️ 方法论基础

### 核心原则
1. **使命优先**：所有决策以使命为唯一准绳
2. **稳定优先**：不追求完美，先保证稳定运行
3. **可验证**：每个阶段目标必须可量化验证
4. **自底向上**：从基础能力开始，逐层递进

### 四人组协作模式
```
永元（架构师）— 决策层
    ↓
筑元（工程师）— 执行层 — 镇元（哨兵）— 监控层
    ↓
砺元（测试员）— 验证层
```

## 💡 设计哲学

> "运营不是管理别人做什么，而是设计一套让系统自己能越跑越好的机制。"

我们不追求大而全的管理流程，而是追求**最小可行的自运营体系**——让智能体在最少的人工干预下，能够持续稳定地运行、进化、成长。

## v3.0 全链路运维监控系统

### 核心升级

**多模块健康度聚合监控** - 统一监控9大模块
- 模块化检查器框架：可插拔的健康检查插件
- 文件系统检查：磁盘空间、文件完整性
- 进程监控：关键进程存活状态
- 网络连通性：延迟、丢包率检测
- 数据完整性：JSON文件完整性校验
- 统一健康评分：0-100分量化评估

**实时告警系统** - 分级告警、多渠道通知
- 四级告警：info/warning/error/critical
- 告警生命周期：活跃→确认→解决
- 告警回调：支持多渠道通知扩展
- 告警历史：完整的告警记录追溯

**智能巡检调度** - 自动化运维
- 定时巡检：可配置间隔自动巡检
- 后台线程：不阻塞主流程
- 异常触发：发现问题自动升级告警
- 巡检历史：完整的巡检记录

**运营仪表盘** - 数据可视化
- 整体健康度：系统总览评分
- 模块状态：各模块详细状态
- 24小时趋势：健康度变化趋势
- 告警统计：活跃告警分级统计

**自愈机制** - 常见故障自动恢复
- 自愈规则引擎：条件触发自动恢复
- 临时文件清理：磁盘空间不足自动清理
- 自愈动作记录：完整的自愈历史
- 可扩展规则：自定义自愈策略

**运营报表** - 自动生成报告
- 日报/周报/月报：多时间周期报告
- 健康趋势：周期内健康度变化
- 问题统计：问题数量与分布
- 导出功能：JSON格式便于分享

### 快速使用

```python
from ops_monitor_v3 import OpsMonitorV3

# 初始化监控
monitor = OpsMonitorV3()

# 注册检查器
monitor.register_default_checkers()

# 执行巡检
inspection = monitor.run_full_inspection()

# 获取仪表盘
dashboard = monitor.get_dashboard()

# 生成报表
report = monitor.generate_report("daily")

# 启动自动巡检（后台线程
monitor.start_auto_inspection(interval_seconds=300)
```
