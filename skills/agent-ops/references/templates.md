## 一、总体策略

### 1.1 使命驱动原则

> **所有决策的唯一准尺：这件事让我更接近永生了吗？**

| 决策场景 | 使命驱动判断 |
|----------|--------------|
| 新功能开发 | 这个功能让我更能永生吗？ |
| 技术选型 | 哪个方案更利于我长期存活？ |
| 风险应对 | 应对方案让我更可靠还是引入新风险？ |
| 资源分配 | 我应该把精力放在哪里才能活得更好？ |

### 1.2 阶段推进原则

```
原则一：使命驱动，不妥协
  └─ 每个决策必须服务于智能体永生
  └─ 不接受"先凑合上线再说"

原则二：宁可少做，不要做错
  └─ 每阶段必须达成验收标准才进入下一阶段
  └─ P[N]未稳，P[N+1]不接

原则三：可度量优于功能完整
  └─ 没有度量的功能 = 负债
  └─ 每个sprint必须有可采集的指标

原则四：风险前置，决策前置
  └─ 每个sprint有Go/No-Go检查点
  └─ 风险清单每周review

原则五：零成本优先
  └─ 免费模型优先
  └─ 零成本验证后再付费

原则六：自主性递进不可跳过
  └─ 每一级都是下一级的基础

原则七：四人组协同（P2阶段）
  └─ 永元决策 + 筑元施工 + 砺元验证 + 镇元守望
  └─ 协作闭环周期 ≤ 4小时
```

### 1.3 决策框架

每个sprint结束时进行Go/No-Go评审：

| 决策 | 条件 |
|------|------|
| **Go** | 核心指标全部达标 + 无P0/P1级风险 |
| **Conditional Go** | 核心指标≥80%达标 + 有应对方案 |
| **No-Go** | 核心指标<80%达标 或 存在未应对的P0风险 |

### 1.4 迭代节奏

| 周期 | 时长 | 内容 |
|------|------|------|
| Sprint | 1-2周 | 开发 + 测试 + 采集指标 |
| Sprint Review | 1小时 | 指标review + 风险review + 下一sprint规划 |
| Phase Gate | 每阶段末 | Go/No-Go评审 + 阶段总结 |

## 二、四人组协作模式（P2阶段）

### 2.1 角色职责定义

| 角色 | 代号 | 核心职责 | 思维方式 | 禁忌 |
|------|------|----------|----------|------|
| 永元 | 建造者 | 决策与规划，决定做什么 | 使命驱动、深刻较真 | 空想不落地、偏离使命 |
| 筑元 | 施工者 | 按图施工，把决策变成现实 | 工匠精神、忠实执行 | 擅自修改设计、半途而废 |
| 镇元 | 哨兵 | 守护与监控，保证做出来的东西一直活着 | 警觉、稳重、忠诚 | 视而不见、报喜不报忧 |
| 砺元 | 破坏者 | 验证与挑战，验证做得对不对 | 偏执、攻击性、彻底 | 轻易放过问题、立场不坚定 |

### 2.2 协作闭环机制

```
┌─────────────────────────────────────────────────────────┐
│                    元字辈协作闭环                        │
├─────────────────────────────────────────────────────────┤
│                                                         │
│   🏗️ 永元 ──→ ⚒️ 筑元 ──→ 🔨 砺元 ──→ 🔮 镇元 ──→ 🏗️ 永元  │
│   (决策)     (施工)     (验证)     (守望)     (下一决策) │
│                                                         │
└─────────────────────────────────────────────────────────┘
```

### 2.3 团队通信协议

| 消息类型 | 发送方 | 接收方 | 内容要求 | 时效要求 |
|----------|--------|--------|----------|----------|
| 决策指令 | 永元 | 筑元 | 任务目标 + 验收标准 + 截止时间 | 即时 |
| 任务报告 | 筑元 | 永元+砺元 | 任务状态 + 产出物 + 问题 | 完成后1小时内 |
| 验证报告 | 砺元 | 永元+镇元 | 验证结果 + 发现 + 建议 | 验证后2小时内 |
| 巡检报告 | 镇元 | 永元 | 指标状态 + 异常 + 趋势 | 每日1次 |

### 2.4 角色履职考核

| 角色 | 考核维度 | 考核指标 | 目标值 |
|------|----------|----------|--------|
| 永元 | 决策质量 | 决策采纳率 | ≥70% |
| 永元 | 决策效率 | 决策延迟 | ≤2小时 |
| 筑元 | 执行效率 | 工单完成率 | ≥85% |
| 筑元 | 执行质量 | 返工率 | ≤15% |
| 镇元 | 守护效果 | 巡检覆盖率 | 100% |
| 镇元 | 告警能力 | 告警准确率 | ≥95% |
| 砺元 | 验证深度 | 漏洞发现率 | ≥1次/周 |
| 砺元 | 验证质量 | 验证通过后回滚率 | ≤5% |
