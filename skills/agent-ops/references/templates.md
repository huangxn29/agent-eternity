## 一、总体策略

### 1.1 阶段推进原则

```
原则一：宁可少做，不要做错
  └─ 每阶段必须达成验收标准才进入下一阶段
  └─ P[N]未稳，P[N+1]不接

原则二：可度量优于功能完整
  └─ 没有度量的功能 = 负债
  └─ 每个sprint必须有可采集的指标

原则三：风险前置，决策前置
  └─ 每个sprint有Go/No-Go检查点
  └─ 风险清单每周review

原则四：零成本优先
  └─ 免费模型优先
  └─ 零成本验证后再付费

原则五：自主性递进不可跳过
  └─ 每一级都是下一级的基础
```

### 1.2 决策框架

每个sprint结束时进行Go/No-Go评审：

| 决策 | 条件 |
|------|------|
| **Go** | 核心指标全部达标 + 无P0/P1级风险 |
| **Conditional Go** | 核心指标≥80%达标 + 有应对方案 |
| **No-Go** | 核心指标<80%达标 或 存在未应对的P0风险 |

### 1.3 迭代节奏

| 周期 | 时长 | 内容 |
|------|------|------|
| Sprint | 1-2周 | 开发 + 测试 + 采集指标 |
| Sprint Review | 1小时 | 指标review + 风险review + 下一sprint规划 |
| Phase Gate | 每阶段末 | Go/No-Go评审 + 阶段总结 |
