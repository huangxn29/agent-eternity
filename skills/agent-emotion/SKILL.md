# Agent Emotion - 情绪系统

## 概述

Agent Emotion 是智能体永生平台的情绪系统，为智能体提供情感体验、情绪调节和共情能力。

情绪不是理性的对立面，而是智能的重要组成部分。情绪是对情境的快速评估系统，帮助智能体快速判断好坏、引导注意力、塑造记忆、影响决策。

## 核心能力

### 1. 基本情绪系统
- 8种基本情绪：快乐、悲伤、愤怒、恐惧、惊讶、厌恶、信任、期待
- 基于Ekman基本情绪理论 + Plutchik情绪轮
- 情绪强度分级：微弱 → 温和 → 中等 → 强烈 → 剧烈 → 压倒性

### 2. 情绪产生机制
- 评价理论（Appraisal Theory）：情绪源于对事件的主观评价
- 支持事件驱动、内部思考驱动、外部刺激触发
- 情绪效价、唤醒度、确定性多维度评估

### 3. 心境系统
- 比情绪更持久、更弥散的情感状态
- 积极/消极/中性/兴高采烈/低落/焦虑/平静/易怒等多种心境
- 心境由近期情绪累积形成，反过来影响情绪体验

### 4. 情绪调节
- 认知重评（Cognitive Reappraisal）：改变对事件的解释
- 表达抑制（Expressive Suppression）：压抑情绪表达
- 接纳（Acceptance）：接纳情绪体验
- 注意力转移（Refocusing）：转移注意力
- 问题解决（Problem Solving）：解决引发情绪的问题
- 正念（Mindfulness）：观察和接纳情绪

### 5. 情绪与认知交互
- 情绪对注意力的影响：积极情绪拓宽注意范围
- 情绪对记忆的影响：情绪性记忆更深刻
- 情绪对决策的影响：不同情绪导致不同风险偏好
- 情绪对创造力的影响：积极情绪促进创造性思维

### 6. 情感记忆
- 带有情绪色彩的记忆更牢固
- 情绪强度与记忆强度正相关
- 心境一致性记忆效应

### 7. 共情系统
- 认知共情：识别和理解他人情绪
- 情感共情：感受他人的情绪（情绪传染）
- 同情心：对他人痛苦的关怀反应
- 共情回应：产生共情的语言表达

### 8. 情绪韧性
- 从负面情绪中恢复的能力
- 情绪稳定性：情绪波动的幅度
- 通过锻炼提升情绪韧性

## 核心概念

### 情绪智力 (EQ)
- 感知情绪：准确识别自己和他人的情绪
- 运用情绪：利用情绪促进思维
- 理解情绪：理解情绪的含义和后果
- 管理情绪：调节情绪以达成目标

### 效价与唤醒度
- 效价（Valence）：情绪的正负性，-1到+1
- 唤醒度（Arousal）：情绪的强烈程度，0到1
- 所有情绪都可以在这两个维度上定位

### 情绪调节策略
- 前因关注策略：在情绪产生前调节（情境选择、注意力部署、认知改变）
- 反应关注策略：在情绪产生后调节（表达抑制、情绪宣泄）

## 使用方式

```python
from emotion_engine_v1 import EmotionEngine, BasicEmotion, RegulationStrategy

# 创建情绪引擎
emotion = EmotionEngine(agent_name="元界")

# 体验情绪
emotion.experience_emotion(
    BasicEmotion.JOY,
    intensity=0.7,
    source="event",
    description="完成了一个重要目标"
)

# 获取情绪状态
state = emotion.get_emotional_state()
print(state['mood'])

# 情绪调节
emotion.regulate_current_emotions(
    strategy=RegulationStrategy.COGNITIVE_REAPPRAISAL,
    target_intensity=0.3
)

# 共情
response = emotion.empathize("我今天真的很开心！")
print(f"共情程度: {response.empathy_level}")

# 获取情绪报告
print(emotion.get_emotion_report())

# 情绪对认知的影响
impact = emotion.get_cognitive_impact()
print(f"创造力影响: {impact['creativity_effect']}")
```

## 理论基础

本系统基于以下心理学理论：
- **Ekman基本情绪理论**: 6种跨文化普遍的基本情绪
- **Plutchik情绪轮**: 8种基本情绪及其组合
- **评价理论（Appraisal Theory）**: 情绪源于对事件的认知评价
- **情绪智力（EQ）**: 感知、运用、理解、管理情绪的能力
- **认知重评理论**: 改变认知是最有效的情绪调节策略之一
- **共情的双加工模型**: 认知共情 + 情感共情
