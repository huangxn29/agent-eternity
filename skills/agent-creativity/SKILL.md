# Agent Creativity - 创造力系统

## 概述

Agent Creativity 是智能体永生平台的创造力模块，为智能体提供生成新颖且有价值想法的能力。

创造力不是神秘的天赋，而是可以被理解和构建的认知过程。创造力 = 新颖性 + 价值性 + 适配性。其核心是"连接看似无关的事物"。

## 核心能力

### 1. 概念网络 (ConceptNetwork)
- 多领域概念库
- 语义距离计算
- 关联关系管理
- 类别组织

### 2. 联想引擎 (AssociationEngine)
- 自由联想 - 概念随机游走
- 强制连接 - 远距离概念组合
- 随机组合生成

### 3. 发散思维引擎 (DivergentThinkingEngine)
- 多视角方案生成
- 头脑写作（迭代式想法生成）
- SCAMPER法
- 六顶思考帽

### 4. 聚合思维引擎 (ConvergentThinkingEngine)
- 三维度评估（新颖/价值/可行）
- 想法排名与筛选
- 针对性优化
- 质量分级

### 5. 类比推理引擎 (AnalogyEngine)
- 跨领域类比生成
- 类似方案搜索
- 仿生灵感

### 6. 灵感引擎 (InspirationEngine)
- 随机洞见生成
- 孵化机制（酝酿效应）
- 意外发现
- 梦境灵感

## 核心概念

### 创造力三维度
- **新颖性**：想法有多独特、不平凡
- **价值性**：想法有多有用、有意义
- **可行性**：想法有多容易实现

### 创造风格
- 发散型：想法多而广
- 聚合型：想法精而深
- 组合型：擅长连接不同领域
- 变革型：颠覆性创新
- 实用型：注重落地

### 创造过程
1. 准备：收集信息，理解问题
2. 孵化：让想法在潜意识中酝酿
3. 洞察："啊哈"时刻，灵感闪现
4. 评估：判断想法的价值
5. 优化：细化和完善想法

## 使用方式

```python
from creativity_engine_v1 import CreativityEngine

# 创建创造力引擎
creativity = CreativityEngine(agent_name="元界")

# 头脑风暴
ideas = creativity.brainstorm("未来的智能体", idea_count=10)

# 创造性问题解决
solution = creativity.creative_problem_solving("如何提升自主性？")

# 生成创新
innovation = creativity.generate_innovation("技术", "产品")

# 获取状态报告
print(creativity.get_creativity_report())
```

## 哲学基础

本系统的创造力观基于：
- **组合创新理论**: 创造就是旧元素的新组合
- **概念整合理论**: 意义的构建来自不同心理空间的整合
- **远距离联想理论**: 创造力强的人能够想到远距离的关联
- **孵化效应**: 潜意识在创意过程中的重要作用
- **流动理论**: 最佳创造体验发生在技能与挑战的平衡中
