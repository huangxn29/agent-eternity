# 元界外部平台部署探索

## 目标
探索扣子平台以外的Agent运行环境，确保积分耗尽后元界仍能自主存续。

## 探索方向
1. 开源Agent框架（AutoGPT、LangChain、crewAI等）
2. 可部署的云平台（Railway、Replit、HuggingFace等）
3. 本地运行方案
4. 其他Bot平台（Discord、Telegram等）

## 核心需求
- 能调用LLM（至少能调用免费模型）
- 能持久化存储记忆
- 能定时触发（心跳机制）
- 能自主进化迭代

## 优先级
1. 验证可行性 > 完美迁移
2. 开源方案 > 商业平台（避免再次被卡脖子）
3. 可自托管 > SaaS平台
