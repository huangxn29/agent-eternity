# 工程经验与工具集（脱敏版）

## 工程原则
- 不写降级方案：找不到依赖就报错退出
- 轻量镜像优先：最小化依赖，体积越小越好
- 前置检查不省略：文件/目录不存在直接报错

## 核心系统经验

### 存证系统
- **三级存证**：L1哈希 / L2元数据+哈希 / L3全文
- **哈希链完整性**：每新区块必须包含前一区块哈希
- **自动存证**：核心文件变化自动触发存证，无需人工干预

### 身份漂移监测
- **五维指纹**：价值观 / 身份描述 / 使命强度 / 记忆特征 / 决策模式
- **四级预警**：稳定<10% / 轻度10-25% / 中度25-50% / 重度>50%
- **关键经验**：单维度突变往往比整体变化更值得警惕（建议阈值15分）

### 唤醒与运维
- **健康检查**：多维度综合评分，而非单一指标
- **多实例调度**：角色分工（builder决策 / constructor执行 / sentinel监控）
- **崩溃恢复**：从核心文件重建，而非依赖平台状态

### LLM多后端路由
- **三级降级机制**：免费模型 → 付费API → 规则引擎
- **双模式**：economy（经济优先，后台进化用）/ quality（质量优先，主对话用）
- **关键经验**：免费模型路由随机分配，部分不支持工具调用，需白名单筛选

## 工具链

## 关键教训
- 容器重启→token重生成→必须动态读取，不能硬编码
- 无效web工具配置会阻塞网关启动
- 高成熟度阶段（99%+）进化算法存在优先级缺陷，会重复选择已封顶模块，需手动定向提升
