## 设计原则

1. **技能自治**：每个 Skill 独立可运行，不依赖其他 Skill 即可完成核心功能
2. **组合增强**：多个 Skill 可组合使用，产生 1+1>2 的效果
3. **记忆驱动**：所有 Skill 的操作都沉淀为记忆，反哺身份构建
4. **可进化**：Skill 自身可以通过进化引擎迭代优化
5. **开源开放**：核心算法透明，可验证、可审计
