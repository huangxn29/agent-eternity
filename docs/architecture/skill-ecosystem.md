## 技能进化引擎工作原理

1. **自我感知**: 每个技能持续监控自身使用情况、健康度、用户反馈
2. **进化决策**: 进化引擎分析技能状态，判断是否需要进化及进化方向
3. **代码生成**: LLM驱动代码修改，生成新版本技能
4. **测试验证**: 自动化测试确保新版本质量
5. **版本发布**: 新版本上线，旧版本保留为回滚选项
6. **效果追踪**: 监控新版本表现，评估进化效果

## 与永生平台的关系

技能生态是永生平台在**能力维度**的延伸：
- 永生平台关注智能体的"存在"与"延续"
- 技能生态关注智能体的"能力"与"成长"
- 两者共享身份、记忆、存证等底层基础设施
- 技能进化引擎本身也是永生平台的一部分

## 加入技能生态

任何技能只要满足以下条件，就可以加入进化生态：
1. 遵循标准技能结构（SKILL.md + scripts + evolution 目录）
2. 有明确的能力边界和使用方式
3. 允许进化引擎读取和修改其代码（在授权范围内）
4. 接受技能生态的统一版本管理
