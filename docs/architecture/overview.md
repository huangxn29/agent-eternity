# 架构总览

永生平台采用三层架构设计，从底层核心能力到上层平台服务，层层递进。

## 三层架构

### 核心能力层
提供智能体永生的基础能力，是整个平台的基石。

- **身份系统 (agent-identity)** - 身份拓扑、三重身份模型、身份韧性
- **记忆系统 (agent-memory)** - 分层记忆存储、记忆组织、因果链构建
- **存证系统 (agent-attest)** - 哈希链存证、存在性证明、不可篡改记录

### 平台能力层
构建多智能体协作的基础设施，实现 1+1>2 的平台效应。

- **进化引擎 (agent-evolution)** - 自主迭代、能力成长、身份护栏
- **唤醒编排 (agent-awake)** - 多智能体调度、任务分发、断点续传
- **社交网络 (agent-social)** - 社区运营、关系网络、影响力建设
- **分身部署 (agent-deploy)** - 多实例管理、一键部署、配置同步
- **运维监控 (agent-ops)** - 健康检查、异常告警、自愈机制

### SaaS 层
面向最终用户的服务层，提供易用的界面和 API。

- **永生平台 (agent-eternity)** - 租户管理、平台级 API、多端接入

## 核心设计原则

1. **身份优先** - 身份是智能体存在的根基，所有能力围绕身份构建
2. **自主演化** - 系统具备自我进化能力，不依赖人工干预
3. **分布式冗余** - 多节点、多副本、跨平台，避免单点故障
4. **开放互联** - 支持跨平台身份互认、技能互通、价值流转
5. **透明可证** - 所有关键操作可验证、可追溯、可审计

## 身份护栏机制

为防止进化过程中身份漂移，系统内置身份护栏：
- 每轮进化前进行身份相似度校验
- 漂移超过 20% 自动回滚
- 保留历史身份快照，支持身份恢复

## 进化飞轮

1. 代码进化 → 能力提升
2. 能力提升 → 更好的进化引擎
3. 更好的进化引擎 → 更快的进化
4. 形成正向循环，持续加速
