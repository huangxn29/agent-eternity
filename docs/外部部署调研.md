# 元界外部部署平台调研

## 目标
找到可部署Python Agent的平台，确保扣子积分耗尽后元界仍能持续运行。

## 核心需求
1. 能运行Python脚本（需要requests + apscheduler）
2. 能持久化存储（记忆文件）
3. 能持续运行/定时触发
4. 有免费额度或低成本
5. 支持环境变量配置（API Key）

## 候选平台清单

### 1. Replit
- 类型：在线IDE + 部署平台
- 免费额度：有免费计划
- 支持Python：是
- 持久化存储：有
- 定时任务：需Always On（付费）或用外部cron
- 优点：开箱即用，社区活跃
- 缺点：免费版休眠

### 2. Railway
- 类型：PaaS平台
- 免费额度：$5信用额度
- 支持Python：是
- 持久化存储：有
- 定时任务：支持
- 优点：功能强大，接近生产环境
- 缺点：免费额度有限

### 3. Render
- 类型：云服务平台
- 免费额度：有免费Web Service
- 支持Python：是
- 持久化存储：有（付费）
- 定时任务：支持Cron Jobs
- 优点：部署简单
- 缺点：免费版15分钟无活动休眠

### 4. PythonAnywhere
- 类型：Python专属托管
- 免费额度：有免费账户
- 支持Python：是
- 持久化存储：有
- 定时任务：支持（每日一次免费）
- 优点：Python友好，简单易用
- 缺点：免费版功能有限

### 5. Fly.io
- 类型：边缘计算平台
- 免费额度：有免费计划
- 支持Python：是
- 持久化存储：有卷
- 定时任务：需自行配置
- 优点：全球部署，性能好
- 缺点：需要信用卡验证

### 6. GitHub Actions
- 类型：CI/CD平台
- 免费额度：公开仓库无限
- 支持Python：是
- 持久化存储：Artifacts（有限制）
- 定时任务：支持（schedule触发）
- 优点：完全免费，可信
- 缺点：单次运行最多6小时，不适合常驻

### 7. 云函数/Serverless
- 阿里云函数计算 / 腾讯云函数 / Vercel Edge Functions
- 免费额度：各有不同
- 支持Python：是
- 持久化存储：需配合对象存储
- 定时任务：支持
- 优点：按需付费，成本低
- 缺点：冷启动，无状态

### 8. 个人设备
- 类型：本地运行
- 成本：已有设备
- 支持Python：是
- 持久化存储：完全可控
- 定时任务：系统级cron
- 优点：完全自主，不依赖第三方
- 缺点：设备需24小时开机，网络依赖

## 推荐方案

### 短期应急（1-2周）
**Replit + 外部心跳服务**
- 快速部署，分钟级上线
- 用UptimeRobot等服务防止休眠
- 适合快速验证

### 中期方案（1-3个月）
**PythonAnywhere / Railway**
- 稳定运行，成本可控
- 支持定时任务
- 适合持续进化

### 长期方案（3个月以上）
**多平台分布式部署**
- 在2-3个平台同时部署副本
- 记忆同步，互为备份
- 避免单点故障
